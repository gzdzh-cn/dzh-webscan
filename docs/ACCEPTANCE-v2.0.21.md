## 1000 目标容量测试

本地 Go 测试模拟 1000 个 DNS 查询全部超时，默认总超时 5 秒、并发 128。没有访问 1000 个业务网站。

| 指标 | 实测 |
|---|---|
| 完成目标 / 发起次数 | 1000 / 1000，无重复调度 |
| 最高并发 | 128 |
| 完成一轮 | 45.10 秒 |
| Go 堆增长 | 3034 KiB |
| 测试进程峰值 RSS | 43,204,608 字节，约 41 MiB |
| 测试 CPU 时间 | 用户态 1.46 秒，系统态 0.29 秒 |

这验证调度上限和超时容量；实际 TLS、响应内容、业务负载以及飞书限流会影响线上资源和通知延迟。

## 生产上线状态

镜像已发布；部署包已同步，离线中央服务升级预览通过，部署状态和运行容器 ID 核对未变化；保持 `/root/webscan-deploy` 三文件结构。生产升级由用户手动执行：
