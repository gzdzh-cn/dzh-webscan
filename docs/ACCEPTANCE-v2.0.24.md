# v2.0.24 SSL 引导与自动部署验收

## 行为

- 首次交互式全量安装先选择 HTTPS/HTTP，显示 YAML 当前模式，回车沿用，0 返回；直接安装命令的 0 退出。旧 YAML 默认 HTTPS。
- 菜单 5 改为“SSL 设置并自动部署”：选择后保存 YAML，直接完整安装或升级主服务器与全部启用节点，同时应用其他 YAML 修改和目标镜像。选择相同协议仍执行完整部署。
- `--set-ssl on/off` 使用同一流程。`--non-interactive` 安装沿用 YAML，不询问协议；帮助、检查、预览和恢复操作不修改配置。
- 原 YAML 注释与值保留，修改前备份到 `/var/lib/webscan-deploy/config-backups/`，文件权限 0600、目录权限 0700。引导锁覆盖保存与部署，保存完成后释放部署锁，供部署工具获取。
- 未完成部署及卸载阻止修改 SSL。部署失败保留所选配置与部署记录，提示继续、回退或排除原因后重试。菜单 1 继续旧安装时使用其锁定的部署工具，不受新脚本及 latest 更新影响。
- 一个开关继续控制事件、指标和后台协议；端口、数据与账号保留。运行服务切换仅在用户主动执行安装或 SSL 菜单时发生。

## 本地验证

- Go 全量测试、go vet、bootstrap 与 deploy 竞态检查通过；前端类型检查、6 项测试、Vite 构建通过。
- Linux amd64 SH 引导隔离验证 10 个场景通过：首次 HTTP、首次 HTTPS 默认值、已安装菜单切 HTTP、相同协议升级、显式非交互 SSL 命令、下载失败、部署工具失败、未完成任务拦截、取消及输入结束。Docker 和部署工具使用模拟入口，证明同一次 SH 操作会启动全量部署工具，部署锁已释放而引导锁仍被持有；未操作生产服务。
- 实际 central + agent + Vector 联调通过：HTTP 约 49 秒；HTTPS 约 110 秒（包括 Vector 首次下载）。真实 PHP 创建/修改/移动/删除、YARA、断网积压、进程重启、接收确认、同容器规则热更新及模拟飞书/Loki 投递排空正常。
- HTTP 后台与真实 HTTPS 反代联调通过：Vue 嵌入资源、登录/退出、Secure Cookie、Origin/CSRF、内部接口隔离、关键词故障和模拟通知投递正常。
- HTTP 联调首次因本地缺少 Vector 且镜像下载暂时失败而中止；固定官方版本缓存就绪后重跑通过。生产网站、Nginx、防火墙和飞书未用于此测试。
- 最终镜像内 Go 程序摘要与发布目录编译产物一致；前端真实产物保存在 `dist/v2.0.24/frontend/`。

## 发布记录

central、agent 的 v2.0.24 与 latest 均已发布；每个镜像的两个标签摘要一致。匿名下载全部镜像层、校验压缩与解压摘要并重新加载后确认镜像身份一致。发布摘要及版本/latest 对应关系记录在 `dist/v2.0.24/release.json`。本地日志、隔离测试结果及服务器私有快照位于 `.cache/ssl-v2.0.24/`，不可公开上传。

主服务器已同步 `deploy-webscan.sh`、`webscan.yaml`、`README.md`；YAML 保留服务器现有选择，同步前后部署状态和所有容器 ID 一致。保留受保护备份，离线主服务器升级预览通过，部署目录仍只有三个文件。同步过程中发现用户的原部署记录发生更新，首次同步被校验阻止；刷新私有快照后保留最新配置及状态完成同步。

服务器留有 v2.0.23 的未完成全量部署（阶段 `central-go-ready`），本次不接管生产切换。用户需先选择菜单 1 继续原任务或按原配置回退，完成后再使用菜单 5 切换 SSL。新脚本恢复旧任务时锁定其原部署工具。
