# v3 运行参数迁移

本模块只用于独立测试库及迁移准备。完整 v3 未完成，**不能据此切换生产**；现有 v2 配置和网页不受影响。

## 已接入范围

从一份通过原 v2 校验的 YAML，一次性初始化 PostgreSQL 运行设置：

| 内容 | 迁入行为 |
|---|---|
| 历史期限 | 保留自定义值；安全期限缺省沿用文件事件期限，服务器告警缺省沿用旧指标历史期限 |
| 网站检测 | 启用、间隔、超时、并发数；不读取或替换数据库中的管理员 |
| 服务器告警 | 保留阈值、持续时间、恢复条件和分组策略；旧采集组件模式转换为 v3 内部规则模式 |
| 飞书与邮箱 | 保留开关、类别、重试、限流和已有通知凭据；不发送测试通知 |
| 备份参数及其他旧期限 | 保存原值，等待 v3 备份、时序保留及相关调度完成后接入 |

不导入 SSH 密码、私钥、注册表密码、旧后台初始化密码、Grafana 密码、节点地址、端口、PKI 路径或部署状态。节点与部署领域必须通过各自迁移及凭据加密流程承接，不能将此命令当作整个部署配置已迁完。

旧 `monitoring.mode` 用于选择采集架构，不是告警开关；迁入后使用 Go 主控规则。实际采样周期仍须在最终切换时与启动配置核对，不能仅导入参数便开始采集。旧 daily_test、备份计划和时序保留值的保存也不代表对应调度已经交付。

## 预览与导入

源文件最多 2 MiB，须为运行账号所有的普通文件，权限仅允许所有者读写，拒绝符号链接。一次安全读取后在内存校验，不重新打开源路径；拒绝读取期间变化、重复键、多文档、版本或参数错误。错误不回显 YAML 内容。

```bash
# 只校验并输出范围和期限；不连接数据库、子控或通知通道。
.cache/webscan-v3 control-v3 --config /绝对路径/隔离-v3.yaml \
  --action preview-settings-v2 --source /绝对路径/旧配置.yaml

# 仅初始化空白设置；先完成 PostgreSQL 一致性备份。
.cache/webscan-v3 control-v3 --config /绝对路径/隔离-v3.yaml \
  --action map-settings-v2 --source /绝对路径/旧配置.yaml \
  --output /绝对路径/私有备份目录
```

飞书启用且使用外部环境文件时明确停止；不会自动读取外部文件或假装保留了未解析的凭据。应先在隔离迁移副本中整理为受保护的 inline 配置，再重新预览。原文件和外部凭据资料应独立保留。

目标必须仍为初始空设置。已有启用节点、实际运行网站、非迁移通知或未完成部署时拒绝初始化。已冻结导入的网站、账号、会话和通知不因此被覆盖，支持先迁参数或先迁网站。

导入使用独占迁移门禁，与正常参数写入及通知领取互斥；一致性备份失败不写配置。设置、迁移保护和不含凭据的审计在同一事务提交，失败全部回滚。重复执行核对已保存的完整内部载荷，不重新备份或修改版本；源或目标变化时停止，不能覆盖。

## 保密与激活边界

报告仅显示范围、期限、设置版本和非通知策略指纹。公开指纹不包含通知地址、用户名、密码、Webhook 或签名密钥，避免变成离线猜密码的依据；重复导入还在内部逐一核对完整规范载荷，不能用相同公开指纹绕过凭据变化检查。

运行设置中的通知凭据供通知工作器使用，仅保存在受访问控制的 PostgreSQL 内部载荷，不进入报告、任务响应或审计。当前模块没有给通知设置增加独立密钥加密；数据库访问和一致性备份应按含凭据资料保护。SSH 仍采用独立密钥加密的凭据仓库，不能混入这些设置。原始 YAML 不复制到数据库。

导入完成固定返回 `ready_for_cutover: false`，持久迁移保护阻止正常登录写入、通知发送、网站检测和历史清理。备份恢复保留期限、设置版本和冻结；不会因导入或恢复而自动激活。

完整配置备份、旧任务／审计承接、网页设置编辑、影子核对、最终增量及激活／回退流程尚需继续。验证见 [本地记录](V3-VALIDATION.md)。
