# v2.0.30 安装入口与交互向导验收

[返回 README](../README.md) · [SH 安装](INSTALLATION.md)

## 功能

- GitHub 简短安装入口、固定版本下载与 SHA256 校验。
- 示例 YAML 首次填写向导，保留注释与高级默认值；取消与 EOF 不提交半份配置。
- 允许无子服务器安装主服务器；SH 和 Compose 同步支持空节点配置。
- 菜单 4 交互录入新节点并直接部署，失败保留节点配置。
- root 全局 `webscan` 管理命令、参数透传及 profile 环境配置。
- 重复执行保留 YAML，同版跳过脚本与模板重复下载，不自动降级，保护未完成任务。

## 自动验证

Go 测试覆盖 HTTP／HTTPS 初始化、取消与 EOF、重复执行、权限、摘要、符号链接、同名命令冲突、并发锁、未完成任务、配置并发变更，以及无节点 Compose 包生成。

Linux amd64 隔离容器使用真实 PTY 执行 `cat install.sh | bash`，网络下载由测试 curl 提供公开测试附件，验证：

- 管道入口可以从 `/dev/tty` 完成向导并进入菜单。
- 无节点配置生成成功，从任意目录执行 `webscan --dry-run` 仅选择主服务器。
- 第二次入口仅获取版本清单，保留 YAML 内容，不重复初始化或下载同版脚本。
- 节点密码输入不回显；模拟镜像下载失败后，新增节点和配置仍保存。
- 已安装但 YAML 丢失时停止，不重新生成模板。
- 没有控制终端时明确拒绝运行。
- 存在其他软件的同名命令时不覆盖，直接执行完整部署脚本仍能进入菜单。

测试未连接业务节点，未发送业务飞书消息。生产服务升级由管理员手动执行；发布与部署包同步不切换容器。

完整前端构建、Go 测试、vet、针对配置／部署／引导的 race 检查与镜像验证记录保存在本地受保护的发布目录，实际公开附件以 GitHub Release 为准。
