# v2.0.34 发布与隔离验收记录

## 已完成检查

- 前端 TypeScript、19 项测试及 Vite 构建通过；Go 全量测试通过，central／notify／website 并发检查通过。
- 页面回归验证服务器选择后清除、组合条件保留、非首页分页重置、URL 参数删除、搜索清除，以及旧请求失败不能覆盖新列表。
- 隔离真实后台中，文件事件由全部 2 条筛选为 1 条，清除后恢复 2 条；列表条件在详情返回后保持。
- 服务器详情的返回按钮、三个适用页签、旧 `/health` 和 `/incidents` 跳转、切换服务器保留最近 7 天及中心健康切子服务器进入链路已核对。
- 网站一次故障一行，中文“已结束”和持续时长正常；邮箱分组、默认关闭状态、历史筛选及结果图已验证。
- 本地 SMTP TLS／STARTTLS 验证中文内容、稳定 Message-ID、认证和收件人拒绝、证书不可信、超时和取消；没有向业务飞书或真实邮箱发送测试。
- 持久化队列验证飞书／邮箱独立开关、固定收件快照、部分成功只重试失败者、重启续投、恢复顺序、共享限流、看门狗入队及测试接口登录／CSRF／限流。
- 首次邮箱表迁移创建 0600 一致性备份；备份失败停止迁移并保留原数据。生产数据库一致性副本迁移后，11 张原有表逐行内容摘要全部保持，包括 1 个管理员、19 个网站、225 条故障、37,034 条事件、38,930 条任务、39,014 条投递记录；迁移前备份为 0600。
- Linux amd64 镜像实际启动通过，真实前端、登录路由及邮箱接口的未登录保护正常。

## 升级后实际验收

```bash
webscan --upgrade --central-only
```

然后打开系统设置 → 邮箱通知，填写并应用 SMTP 配置，主动发送测试邮件，同时核对通知历史和实际邮箱。当前仅验证隔离 SMTP，未验证任何真实服务商的收件情况；生产升级、真实邮件与故障演练由管理员按需要执行。未进行本次生产回退演练。
