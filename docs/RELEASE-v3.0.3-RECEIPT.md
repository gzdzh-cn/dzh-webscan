## 失败修复与测试预算

第一次候选在 Docker 29 的证书恢复资源检查超出累计 30 秒；本版将完整维护检查预算设为 90 秒，保留单条只读命令 10 秒、原授权到期、取消、租约及全部身份／资源断言。修复后资源检查超过 30 秒仍可完成并通过真实 mTLS 复验。

第二次当前产物联合测试触及夹具 22 分钟总时限，未标为通过。最终重跑仅通过可追溯 Go test overlay 将总时限改为 28 分钟、Go test timeout 改为 30 分钟，不改变正式程序、单次操作、授权、租约或断言。原失败日志及覆盖摘要保留。该夹具调整在发布后的独立文档／测试提交中同步，发布标签仍固定实际构建提交。
