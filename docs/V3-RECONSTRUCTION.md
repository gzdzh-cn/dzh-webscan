# v3 主控与子控重构进度

当前为本地基础重构代码，**完整 v3 尚未交付，不支持生产切换**。已发布版本仍为 v2.0.46；普通安装、升级、网页和 YAML 沿用 v2 逻辑。原有未提交的 Docker 镜像导入修复保留。

最新进展：节点本机续期、过期恢复和 TLS 名称变更已接通宿主持久授权、固定 SSH 工具及独立重新授权续作。名称目标配置已有 PG 和两种方式的文件／SQLite 阶段应用及保留新增事件的回退验证；真实 native 和 Docker 27.5.1 内核应用／回退已通过；Docker 29 子控兼容仍待验证。旧 SAN 裁剪已有独立本机原语、真实回环 mTLS、PG 依赖检查及 schema 34 持久授权／唯一共享发行账本，保护保留快照所需名称；固定 SSH、独立重新授权与历史退役尚未接入。完整 SSH＋Agent＋服务管理联验、CA 换根、完整安装、高可用、最终迁移及规模门禁仍需完成。完整 v3 尚不能发布，详见 [证书生命周期](V3-PKI.md)、[真实内核验收](V3-KERNEL-VALIDATION.md) 和 [验证记录](V3-VALIDATION.md)。

此前 [真实 x86_64 内核、systemd 与 Docker 验收](V3-KERNEL-VALIDATION.md)已通过 v3 native↔Docker 双向切换，以及正式 v2.0.34 Agent 与两个活动 sidecar 的单次整组迁移和回退；旧包装服务、纯 Compose 分别有独立结果。这些历史结果不替代本轮连续替换／逐级回退的联合验收。完整中心安装、证书运维、中心最终切换及规模验证仍需继续，不代表已满足发布门槛。

本版范围是 Go 主控、Go 子控、现有 Vue 3 网页和部署工具。未来桌面端采用 Vue 3＋Vite＋Wails v3，Android 采用 Kotlin＋Jetpack Compose，本轮没有添加客户端工程。首版主控仍要求公网可达；VPN、中继和无公网入口建设未实施。

## 本地隔离验证

执行：

```bash
scripts/verify-v3-foundation.sh
```

脚本创建仅绑定回环地址的临时 PostgreSQL 和 VictoriaMetrics，用独立 schema 运行测试，结束后删除自己创建的容器及匿名卷。不会读取生产 `webscan.yaml`、连接部署中的后台或发送真实通知。测试库的 trust 认证仅用于这个临时环境。

验证内容包括真实 PostgreSQL／VictoriaMetrics 读写、事务回滚、幂等去重、确认丢失、租约接管及失效、关闭暂停与限流、会话持久化和密码重置撤销。还会运行 Go 全量测试、前端类型检查、测试、构建及 Linux amd64 编译。

Linux Agent 运行测试需要已有含 YARA 等工具的测试镜像。脚本默认使用本地 `gzdzh/webscan-agent:v2.0.46`，可通过 `WEBSCAN_V3_AGENT_TEST_IMAGE` 指定隔离镜像；未找到镜像时会明确记录未运行，不会伪报通过。Agent 测试容器使用 `--network none`。本次编译的验证 CLI 标记为 `v3.0.0-local-test`，仅在临时目录和容器使用，不是发布版本。严格原生进程归属测试在 Rosetta 转译环境跳过，转译生命周期另设用例；生产归属规则保持严格。独立容器还验证实际 CPU、内存及文件句柄限制的读取，不能替代 systemd 安装验收。

systemd 单元解析可使用独立验证镜像，构建只安装校验工具，不启动 systemd 或任何生产服务：

```bash
docker build --platform linux/amd64 -f scripts/Dockerfile.v3-systemd-validator \
  -t webscan-v3-systemd-validation:local .
WEBSCAN_V3_SYSTEMD_TEST_IMAGE=webscan-v3-systemd-validation:local \
  scripts/verify-v3-foundation.sh
```

镜像基础摘要及 systemd 软件包版本固定。未指定镜像时明确跳过外部 systemd 解析；Compose 验证只创建并删除自己的停止状态测试容器，不启动 Agent。

实际 clamd 自检可使用隔离镜像。测试临时启动自己的 clamd，只加载无害本地测试签名，使用独立 Unix socket，不运行 freshclam、不下载病毒库、不访问宿主机扫描服务：

```bash
docker build --platform linux/amd64 -f scripts/Dockerfile.v3-scanner-validator \
  -t webscan-v3-scanner-validation:local .
WEBSCAN_V3_SCANNER_TEST_IMAGE=webscan-v3-scanner-validation:local \
  scripts/verify-v3-foundation.sh
```

该测试验证实际客户端扫描和服务停止后的就绪失效，不代替生产扫描库效果、资源容量或 native／Docker 完整安装验收。

测试数据库镜像固定摘要，仅用于复现验收，不构成生产数据库版本选择。结果记录在 `.cache/verification/v3/run.*/`。[已执行验证和缺口](V3-VALIDATION.md)。

## 独立命令入口

开发者可用 `go build -o .cache/webscan-v3 ./cmd/webscan` 构建本地工具。以下示例只用于隔离环境；`control-v3` 不会调用既有 `webscan --upgrade`。

```bash
# 首次配置；交互选择回车为 single。
.cache/webscan-v3 control-v3 --action configure --config /tmp/webscan-v3-lab.yaml

# 非交互默认 single，不覆盖已存在的配置。
.cache/webscan-v3 control-v3 --action configure --non-interactive \
  --config /tmp/webscan-v3-lab.yaml --public-url https://monitor.example.test

# 静态配置和角色布局预览；network_verified=false，不代替网络检查。
.cache/webscan-v3 control-v3 --action check --config /tmp/webscan-v3-lab.yaml
```

配置样例见根目录 `webscan-v3.example.yaml`。PostgreSQL DSN 和初始密码通过私有文件读取，不放入命令行、URL、日志或仓库；文件应为 0600、属于运行账号，禁止符号链接。没有后台 TLS 时只允许监听回环地址，由 HTTPS 入口代理。当前 API 提供独立内嵌 v3 网页，发布版 v2 入口不变；当前已接入登录、总览、服务器登记与详情、网站监控、文件事件、告警中心、历史设置与清理、两类配置存档和部署任务日志；运行设置白名单和部署配置保存态恢复已接通；配置实际应用协调及公开部署仍未完成。

仅在新建的隔离 PostgreSQL 中执行 `--action init-db`。之后使用 `--action provision-admin --username <账号> --password-file <私有文件>` 创建账号，再用 `--action run --role api|collector|notifier|websites|all` 启动已实现角色。`reset-password` 通过同样的私有文件重置密码，并原子撤销该账号全部会话。业务 schema 现为 28；已有 schema 1～27 须用 `migrate-db --output <私有备份目录>` 先备份再升级，拒绝无备份升级及版本降级。API／all 包含受迁移保护约束的自动历史清理，见 [保留与清理](V3-RETENTION.md)。完整生产切换仍未交付，不能将开发库直接接管生产。

高可用初始化只收集和验证三台独立机器、SSH、内部地址及 HTTPS 入口，输出规划角色；不会安装 Patroni、etcd、VictoriaMetrics 集群或检查真实入口容灾。`central.topology: ha` 不是已完成高可用验收的证明。

## SQLite 暂存与恢复边界

```bash
# 源库只读清点。
.cache/webscan-v3 control-v3 --config /tmp/webscan-v3-lab.yaml \
  --action preview-v2 --source /绝对路径/隔离源库.sqlite3

# 先创建一致性快照，再按 500 条短事务写入暂存区。
.cache/webscan-v3 control-v3 --config /tmp/webscan-v3-lab.yaml \
  --action archive-v2 --source /绝对路径/隔离源库.sqlite3 --output /绝对路径/隔离备份目录

# 中断后使用原报告中的 snapshot；不重新读取变化中的源库。
.cache/webscan-v3 control-v3 --config /tmp/webscan-v3-lab.yaml \
  --action archive-v2 --snapshot /绝对路径/原快照.sqlite3
```

快照为 0600、备份目录为 0700。暂存区按快照 SHA256 绑定检查点，保留大整数、BLOB、NULL 和原业务字段；恢复时重新核对数量及重复记录摘要。单源任务有租约保护，失败报告保留已完成部分与快照位置。无稳定 rowid 的表明确失败，不静默跳过。
