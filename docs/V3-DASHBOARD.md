# v3 监控总览：本地接入与边界

独立 v3 网页根路径 `/` 已接入总览。发布版仍为 v2.0.46，本页不表示完整 v3、正式升级或万台容量验收已经完成。

## 页面与读取

页面按六组摘要、当前异常、组件、三项资源排名和服务器资源表展示。顶部使用实际构建版本和汇总更新时间；API 另提供当前后台进程启动时间。

- 服务器摘要区分启用、正常、异常和未知；暂停网站单独统计。
- 24 小时事件排除 `probe`，采用与事件页一致的原生／迁移去重规则，不重复计算已存在原生回执的旧展示副本。
- 当前异常最多八项，服务器来自现有 firing 规则，网站来自未结束故障／证书／慢响应记录；排除停用节点及已暂停、已删除、待迁移的网站。详情与查看全部均进入已有管理页面。
- 三项 ECharts 排名分别从全部启用节点的有效新鲜采样取前十，不能从资源表当前二十台推算。资源表按编号展示前二十台，包含配置方式、实际方式、Agent 版本及采样时间；更多节点进入服务端分页的服务器管理。
- 缺失和非法数值显示 `—`，有效零值仍显示 `0.0%`。新鲜度为采集间隔的三倍，最少六十秒；异常未来时间不作为新鲜证据。页面三十秒刷新不改变实际采集周期。

后台汇总工作器每十秒竞争持久租约并生成缓存。HTTP `GET /api/v3/dashboard` 要求登录，**只读取缓存**，不逐台查询、执行命令、检查文件、扫描目录或做数据库完整性检查。冷缓存返回 503，不返回伪造的全零健康总览。

九个固定分区分别记录 `data`、`updated_at` 和安全 `error`。每项读取有七百五十毫秒预算，整轮八秒；失败保留该项上次数据和观测时间，首次失败为 null，其他分区继续。缓存生成时间不能代替分区观测时间。旧计数字段保留；过期缓存和异常查询失败不展示“当前没有异常”。

网页请求完成后等待完整三十秒，再发起下一次读取；手动刷新立即读取，不与在途请求重叠。后台标签取消读取并暂停计时，返回前台读取一次。退出、路由切换与旧请求不会覆盖新页面；失败保留已显示内容，下一周期重试。

## 十三张组件卡

| 卡片 | 已接入证据 | 当前限制 |
|---|---|---|
| 中心接收与后台 | 当前 API 可访问、实际版本 | 不能代替全部中心角色验收 |
| 主机指标采集 | 新鲜／异常／未知适用节点数 | 未采到样本不算正常 |
| 文件监控 | 新鲜样本中的 Agent 心跳及覆盖 | 缺失心跳／覆盖为未知 |
| 安全扫描 | 配置中 YARA／ClamAV 适用数量、心跳、已观测待扫描 | 配置启用数不表示引擎实际自检通过；单引擎心跳待继续细分 |
| 事件投递 | 已观测积压、最老等待及已有错误 | 现有状态不能证明逐节点最近成功轮询，成功心跳待继续接入 |
| 网站检测 | 现有调度心跳、待检查及暂停／迁移数量 | 未观察到调度心跳为未知 |
| 数据库 | 当前应用 PostgreSQL 可访问及表／索引大小 | VictoriaMetrics 访问证据及大小待接入，卡片整体保持未知 |
| 飞书通知 | 启用、待投递及重试 | 尚无专用投递工作器心跳，空队列不能推断正常 |
| 邮箱通知 | 独立通道的启用、待投递及重试 | 关闭通道保留队列；没有向业务邮箱发测试消息 |
| 宿主管理服务 | 已有部署执行器心跳 | 心跳不等于完整安装／应用验收 |
| 看门狗 | 明确未接管 | v3 运行状态及维护阶段待接入 |
| 备份与历史清理 | 清理工作器心跳、最近结果及数量 | 自动数据库备份证据待接入，不能整体标正常 |
| 部署任务 | 排队／运行、恢复职责和最近结果 | 当前仍不开放不完整的公开部署提交 |

状态以中文文字及符号表达，支持正常、异常、未知、已停用、未接管和后续维护状态。旧 Vector、node-exporter 不作为新架构必需项。全局或分区数据过期后，相关状态转为未知并保留原因，不能沿用绿色正常。

进入文件事件页只携带筛选，仍须手动查询；总览没有删除入口，系统设置也没有新增删除按钮。

## 验证范围与后续

使用真实 PostgreSQL、隔离 Linux amd64、Vue 挂载测试和本地合成数据浏览器验收。桌面和窄屏均检查，资源表在自身区域横向滚动，页面没有整页横向溢出；不连接生产节点或业务通知。

当前事件计数仍由后台有界聚合生成，尚未完成大规模增量计数及真实吞吐验证；读取超预算会显示过期数据，不能据此承诺万台性能。还需接入表中缺失的运行证据、完整配置保存／下发／生效、实际部署与 PKI 运维、生产迁移和回退、单中心／可选 HA 安装，以及 10,000／20,000 节点和 72 小时验收。完整门禁通过前不发布 v3 或修改 `latest`。
