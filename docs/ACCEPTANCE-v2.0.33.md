## 迁移过程中的修复

v2.0.31 的指标导入遇到 SQLite 写入争用，旧组件继续运行，没有进入切换阶段。v2.0.32 预先取得写锁，修复争用问题；进一步检查发现未完成历史数据可能被实时压缩，因此暂时中断导入，发布 v2.0.33 增加持久化保护并重新导入核对。旧 Prometheus、Loki 数据作为原始来源保留。

## 验证边界

没有在生产故意停机、制造故障通知或执行回退演练；没有新增真实子服务器作为测试目标，也没有进行 50 台服务器、1000 个网站的生产长期压测。本地负载与隔离恢复测试记录见 [v2.0.31 本地验收](ACCEPTANCE-v2.0.31.md)。本次不改业务网站、Nginx、通信协议或防火墙。
