# v3.0.4 服务器详情指标修复

本补丁基于已发布的 v3.0.3，只调整历史指标查询与详情页错误处理，不包含开发分支中的后续业务功能。数据库结构、子控通信协议和安装资料格式保持 v3.0.3 的兼容范围。

VictoriaMetrics 范围查询现在明确保留请求的时间网格，避免一小时窗口起点未经对齐时，被缓存查询改写后触发主控的严格边界校验。节点身份、时间范围、步长、序列数和点数限制仍然生效。关闭此类查询缓存会增加重复历史查询的计算量。

详情页将已识别的 `503 metrics_unavailable` 显示在曲线区域，保留节点详情及已有曲线；真实网络中断、其他可重试错误和鉴权失败继续沿用原处理规则。

发布工具支持先发布固定版本，再凭匹配的线上验收回执更新 `latest`；来源检查核验当前发布分支的实际远端上游与构建提交。全部十九项正式门禁、签名和摘要检查保持启用。

验收状态以本次实际构建对应的发布回执为准。历史 v3.0.3 回执不替代本补丁产物验收。中心更新不要求升级 PostgreSQL、VictoriaMetrics 或子控；更新前仍需核对运行来源并验证一致性备份。
