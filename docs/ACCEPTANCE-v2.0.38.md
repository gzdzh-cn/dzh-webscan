# v2.0.38 验证记录

本版完善子服务器私钥录入和页面交互，删除保护规则保持原样。普通升级仅更新中心及宿主管理服务，子服务器无需升级。

## 已通过

- 前端 TypeScript 检查、34 项 Vitest 及 Vite 构建，全量 Go 测试。
- Linux amd64 镜像实际启动：嵌入页面、登录入口、未登录接口保护及内部主机采集正常。
- 私钥文件选择、拖入与粘贴共用校验，覆盖单文件、64 KiB 限制、读取竞争和关闭弹窗后的迟到结果。
- 未加密 OpenSSH／PEM 私钥解析；公钥、加密私钥、损坏内容、超限及路径／内容冲突拒绝。
- 隔离浏览器验证选择文件后读取内容、预览不写文件、仅保存、再次编辑不回显私钥、留空保留；隔离 SSH 服务验证生成文件可认证。
- 目录及文件权限、符号链接拒绝、备份／写入失败、并发配置修改、替换保留旧文件及部署失败保留已提交配置。
- 修复脱敏状态字段的遍历不稳定；验证已配置标记保持一致。
- 文件事件刷新仅保留预设下拉框，旧自定义偏好回到 30 秒；服务器返回与网站详情一致，总览没有重复标题。

测试不修改生产节点私钥，不向业务飞书或真实邮箱发送测试消息。配置备份仅保存私钥路径，迁移与灾备需另外保存私钥文件。

## 发布及升级

构建产物位于 `dist/v2.0.38/`，发布时核对版本与 latest 镜像摘要、安装清单及附件校验值。生产升级前创建一致性数据库备份并保存当前配置；升级后核对账号、网站、历史、通知及子服务器状态。

```bash
webscan --upgrade --central-only
```
