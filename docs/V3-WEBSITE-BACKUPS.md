# v3 网站配置备份

这是本地重构模块，完整 v3 尚未交付，不能用于生产切换。现有 v2 页面及备份接口保持原样。

## 保存范围

网站快照保存网址、名称、关键词、关联节点、慢响应告警及暂停状态。不包含监控数据库、故障历史、后台密码、SSH 私钥或通知凭据。完整灾备仍需一致性 PostgreSQL 备份及外部配套资料。

快照和元数据同事务保存在 PostgreSQL。手动备份来自当前已保存的网站配置；导入仅加入备份列表，不立即恢复或部署。来源为手动、导入或恢复前自动备份。

## API

所有接口要求登录；写入要求角色、CSRF 和来源校验。创建、导入、删除及恢复要求 `Idempotency-Key`，重试不重复操作。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v3/website-backups` | 游标分页，每页 1～200 条 |
| POST | `/api/v3/website-backups` | 手动快照 |
| POST | `/api/v3/website-backups/import` | 导入原 format_version: 1 JSON |
| POST | `/api/v3/website-backups/delete` | 删除明确选择的 1～200 个备份 |
| GET | `/api/v3/website-backups/:id/export` | 校验后导出 JSON |
| POST | `/api/v3/website-backups/:id/preview` | 生成合并预览 |
| POST | `/api/v3/website-backups/:id/restore` | 提交预览凭据并合并 |

导入上限 2 MiB，拒绝重复 JSON 键、未知字段、无效配置及重复规范化网址。内部快照上限 24 MiB、100,000 个网站；这些是保护上限，不是已验证容量。列表包含 `record_key`、`can_delete` 和 `delete_reason`，部分删除返回具体跳过项。

## 恢复保护

预览有效 10 分钟，绑定账号、备份摘要、网站配置版本及节点版本。正常检测结果不会使预览失效，配置或节点变化则要求重新预览。原始凭据不写入审计，只保存摘要。

恢复先在同一事务备份当前配置，再按规范化网址合并，不删除备份中没有的网站。软删除网站复用原 ID；历史和已排队通知保留。不存在的关联节点列入预览并清除关联。检测规则变化或恢复软删除网站时重置检测状态，使旧租约和结果失效，不生成恢复通知。

SQL 每批最多处理 500 个网站，所有批次属于一个事务，任一失败整次回滚。正常网站编辑、删除、快照与恢复共用配置锁；节点登记在恢复期间保持一致。迁移冻结期间禁止创建、导入、预览、恢复和删除。

有效恢复预览引用的备份禁止删除；独立备份不适用历史记录的 24 小时保护。删除只移除备份载荷和元数据，不改变网站，不保证立即释放数据库文件大小。

## 数据库升级与边界

schema 10 增加备份及预览表；schema 1～9 升级前必须完成校验过的一致性备份，失败停止。灾备恢复保留网站和备份，清除全部临时恢复预览，要求重新授权。

## 旧网站备份迁移

先用 `archive-v2` 对旧网站 SQLite 创建一致性快照并归档，保留报告的 SHA256，再指定原网站备份目录的受保护副本：

```bash
webscan control-v3 --config /private/lab.yaml --action map-website-backups-v2 \
  --source <归档报告的 SHA256> --backup-directory /private/website-config
```

该目录只能通过离线 CLI 提供，HTTP 接口不能指定服务器路径。目录须为运行账号所有的 `0700` 目录，每份文件为 `0600`；拒绝符号链接、非普通文件、超限文件和不合法编号。先核对旧元数据摘要与原始文件，再校验格式和网站数量；保留原始时间、来源、恢复时间及结果。新记录 ID 按源快照和旧 ID 确定性映射，原编号保存在 `result.legacy_id`，原始元数据仍完整保存在无损归档中。

每次事务只迁移一个文档，限制大型快照的事务内存；续作从已提交检查点继续，不重复导入。文件缺失或摘要变化时停止，保留已完成部分及迁移保护。导入完成后载荷由 PostgreSQL 保管，不依赖旧目录继续存在；操作重试仍须提供已有私有目录。

旧系统如有排队或运行中的网站备份删除任务，绑定目标前即拒绝；先在旧系统完成任务并重新归档。已结束删除任务的审计只保留在归档内。旧恢复预览不迁移为有效授权。

映射不恢复任何网站，不启用检测或通知。该领域保持 `pending`，结果始终 `ready_for_cutover: false`；普通写入和删除继续受迁移保护。

独立 v3 Vue 网站备份页已接入手动快照、原始 JSON 导入、导出、账号绑定合并预览与恢复、明确选择删除及保护原因，详见 [网页接入](V3-CONSOLE.md)。部署配置备份及旧部署／审计任务的业务承接尚未接入。这个模块不能替代完整 v3 迁移、回退、HA 和容量验收。
