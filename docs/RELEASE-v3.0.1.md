# v3.0.1 中心 UI 恢复补丁

2026-10-30 已正式发布，17 个公开附件、两种签名及两个镜像 latest 摘要复核通过。实际源码、产物及门禁见 [发布回执](RELEASE-v3.0.1-RECEIPT.md)；本次未升级生产。

以 v2.0.46 为视觉和交互基准，恢复登录、导航、监控总览、服务器与网站详情、文件事件、告警、设置、部署日志和备份页面。继续使用 v3 主动采集与 `/api/v3`，不连接旧中心。

- 恢复原统计卡、图标、表格列序、页签、工具栏、详情返回按钮及长表单布局；手机端正文滚动、固定操作反馈。
- 增加安全的服务器展示字段、受限历史指标查询和七日通知聚合；未知数据不填假零，曲线缺口保留。
- 保留事件首次手动查询、删除保护、游标分页、私钥拖入、独立升级不保存草稿及部署日志续读。
- 修复未采集节点状态为空时的数据库读取错误。

## 验收与边界

前端类型检查、220 项测试、构建，以及真实 PostgreSQL／VictoriaMetrics 的 16 项相关 Go 竞争检查通过。真实 Chrome 桌面和手机对照覆盖 24 组状态，见 [逐页对照](V3-UI-COMPARISON.html) 与 [验收及差异](V3-UI-RESTORATION.md)。本版正式产物生命周期及全部发布门禁已通过，具体证据与限制见发布回执。

本补丁不新增业务写接口。改密、卸载、设备级历史曲线和公共文件规则编辑等尚无 v3 接口的功能继续禁用或显示“未提供”；不宣称完整旧版功能等价。

主控与子控镜像使用可读 `v3.0.1` 标签和固定摘要，内置实际本版程序；发布包包含签名、摘要及构建验收资料。安装信任与维护步骤沿用 [本版安装指南](INSTALL-v3.0.1.md)，下载时选择 v3.0.1 对应附件及请求示例，不能混用 v3.0.0 固定摘要。

本次只提交及发布，不升级生产主控或子控，不迁移或删除旧主控数据。高可用、万台容量认证不属于本补丁范围。
