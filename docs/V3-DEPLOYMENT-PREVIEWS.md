# v3 部署预览与确认

当前公开网页流程、外部执行器、凭据及恢复接口见 [网页部署说明](V3-WEB-DEPLOYMENT.md)。新接口已接入，能力由真实信任资料和工作器心跳决定；正式验收仍以发布记录为准。

以下为此前分阶段实现记录，涉及“公开写入未开放”的表述仅描述当时边界。

当前实现用于隔离环境中的本地管理员命令。HTTP 部署写接口仍返回 `503 executor_unavailable`，Vue 页面尚未接入。预览不连接 SSH、不检测远端环境，也不证明目标节点已经安装成功。

## 准备、预览和确认

先按[节点配置包说明](V3-NODE-CONFIGURATION.md)登记 SSH 凭据、校验发布签名并生成私有配置包。之后：

1. `preview-deployment` 读取已经准备的部署请求，核对已保存的节点、当前采集信任、发布清单及凭据，返回有效十分钟的预览。
2. 管理员核对节点、部署类型、配置版本、实际方式及目标版本／摘要。已有可信成功记录时展示当前版本；没有证据时显示 `unknown`。
3. 将返回的 `token` 写入私有确认 JSON，调用 `confirm-deployment`，提供稳定的 `--request-key`。这一步只创建排队任务；独立执行器启动后才可能安装。

```bash
umask 077
webscan control-v3 --config /私有目录/control.yaml \
  --action preview-deployment --username admin \
  --source /私有目录/request.json > /私有目录/preview.json

# 阅读 preview.json，将其中 token 写入私有 confirm.json：{"token":"返回的值"}
# 不要将 token 放入命令行、终端历史、日志或仓库。
webscan control-v3 --config /私有目录/control.yaml \
  --action confirm-deployment --username admin \
  --source /私有目录/confirm.json --request-key install-node-a-1
```

输入仍要求私有普通文件、规范绝对路径，最大 128 KiB，拒绝链接、未知字段和重复键。确认只接受 `token`，不能夹带编辑草稿、任意路径或命令。`queue-deployment` 保留为可信本地底层入口，不具备用户预览确认语义，不应直接映射到网页。

## 绑定与失效

数据库仅保存随机 token 的 SHA256。预览绑定：

- 管理员账号及账号版本；改密、重置或撤权后失效，重复请求也重新检查权限。
- 节点版本、已生效版本、方式、完整配置摘要和身份资料。
- 已验签发布清单、目标程序及不可变配置包摘要。
- SSH 凭据版本，以及节点最近部署记录和恢复责任。

新任务、配置修改、凭据换钥或远端部署状态变化后重新预览。普通指标更新及其他节点编辑不影响当前预览。确认再次读取包和当前 CA／CRL、校验节点身份与允许采集身份，并在节点行锁内核对状态。等待锁不能延长十分钟有效期。

确认采用可重试的 PostgreSQL REPEATABLE READ 事务，捕获原始启动配置与全部已保存配置的加密 `before_deploy` 存档，并将其 ID 绑定进不可变任务摘要。存档、任务引用、预览消费、任务、初始日志、防重回执和审计同一事务提交。任何一步失败全部回滚；使用原请求键可重试。重复确认只返回原任务，换请求键不能重复消费 token；成功后的回执可在预览过期后重取，但账号权限和版本仍须有效。

每账号最多 100 个未消费有效预览，跨进程串行核对上限。过期未消费预览分批回收，跳过正在使用的行；已消费记录保留原任务绑定，避免清理后丢失防重依据。日志、任务与审计没有 token 原文、SSH 凭据、证书私钥或本地路径。

## 升级判断

可信当前版本仅来自与 `applied_version` 对应的成功部署计划。确认相同版本、目标摘要和已生效配置时返回无需升级；可比较的 SemVer 明确低于当前版本时拒绝降级。已有方式与已保存目标方式不同，拒绝通过升级入口切换。缺少旧记录或旧版本不可比较时返回未知，不伪造已安装版本。

这些判断不代替部署前环境检查、服务验收、证书轮换或旧三容器接管。后续公开流程还需接入服务器选定的规则和身份资料，以及网页预览／确认；浏览器不能传入本地准备命令支持的文件路径。

存档密钥缺失、配置无法完整捕获、分块或引用写入失败均停止创建任务，不消耗预览。重放已成功的请求只返回原任务，不新建存档。40001／40P01 冲突最多执行五次本地事务，不在重试事务内操作远端；其他错误不自动重试。

## 数据库与恢复

schema 12→13 新增预览表及节点部署历史索引。已有数据库必须先完成一致性备份；备份失败不执行迁移。灾备同时保留预览、任务及回执，仍需要外部 Vault 密钥、信任资料和私有配置包。数据库恢复不代表远端阶段已核对，不得直接重做远端操作。
