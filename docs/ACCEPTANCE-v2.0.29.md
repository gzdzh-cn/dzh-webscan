# v2.0.29 后台完善验收

本次增加持久化管理员改密、网站配置备份与合并恢复、证书到期展示，以及网址复制和新标签打开。仅主服务器需要升级，通信协议与子服务器容器保持原配置。

## 数据兼容

- 管理员表与备份历史表采用增量迁移。既有网站表、故障历史、文件事件和投递任务不重新导入。
- 使用线上一致性 SQLite 副本在隔离环境迁移，对五张既有表逐行计算摘要，迁移前后一致：18 条网站、30 条故障记录、13,622 条文件事件、15,034 条投递任务记录及网站通知缓冲表。
- 迁移前备份创建失败时停止，不留下新表或部分迁移。
- 首次升级使用当前运行配置初始化账号；新填 YAML 不覆盖当前账号。已有持久化账号始终优先。
- 本次验证与发布没有升级生产容器，测试不向业务飞书发送消息。

## 功能与故障场景

- 密码字段提示、CSRF、错误当前密码限流、所有会话撤销、管理员终端重置。
- 实际 Linux amd64 镜像中验证改密后重启、v2.0.28 回退、再运行 v2.0.29，以及真实 PTY 不回显密码的 root 重置命令。
- 内部管理令牌验收在改密后继续成功；公网事件监听及后台 API 不暴露内部验收。
- 配置备份、导出和导入、历史持久化、合并恢复、软删除记录复用、未知节点提示、旧任务结果丢弃。
- 预览后配置变化拒绝恢复；备份目录失败及事务中途失败不留下部分配置；已有队列和故障历史保留。
- 重复网址、非法地址、格式版本、2 MiB 导入限制与 1000 个网站限制。服务器本地备份覆盖全部合法配置，可恢复大于导入限制的本地快照。
- 隔离证书验证精确 7 天阈值、过期握手、首次过期补发、24 小时去重、续签恢复、404、首个 HTTPS 跳转和网络失败保留信息。
- Grafana 使用剩余天数与未知数据，保留旧指标兼容性。
- Chrome 验证中文页面、网址换行、复制完整查询参数、备份创建、合并预览与恢复，以及刷新访问备份路由。网址新标签属性、独立复制事件、HTTP 兼容复制、失败手动复制和证书天数由前端测试覆盖。

## 手动生产升级

```bash
cd /root/webscan-deploy
bash deploy-webscan.sh --upgrade --central-only
```

升级后用原密码登录；改密后使用新密码。用独立测试网站检查备份恢复及证书展示，再继续管理业务网站。使用说明见 [网站后台指南](WEBSITE.md)。
