## 修复与使用

服务器管理支持单条及当前页最多 200 条批量“移除记录”，失联节点无需 SSH。确认后停止中心采集，保留历史事件、指标、任务、审计及远程程序。关联网站、未完成部署、恢复任务和有效身份维护任务显示具体保护原因；节点 ID 保留作历史关联，重新接入需使用新 ID。

升级不会自动移除任何节点。线上浏览器已验证失效记录的确认弹窗及取消行为，实际移除留给管理员操作。
