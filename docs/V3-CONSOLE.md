# v3 网页接入与本地验收

本文说明 v3 网页后台及本地验收范围。本轮以 v2.0.46 的页面结构恢复 UI，继续使用 `/api/v3`，未切换线上入口。逐页桌面／手机对照、剩余差异及本轮验证见 [UI 恢复记录](V3-UI-RESTORATION.md)。

## 构建与入口

`web/vite.config.ts` 同时构建 `index.html`（现有 v2）与 `v3.html`。Go v3 API 角色从内嵌资源提供独立 v3 页面，不回退到 v2 的 `/api` 接口。更新网页后须重新构建前端并编译 Go；仅修改网页源文件不会更新已启动的内嵌程序。

```bash
npm --prefix web run typecheck
npm --prefix web test
npm --prefix web run build
go build -o /tmp/webscan-v3-console ./cmd/webscan
```

入口使用已经配置的 v3 API 监听地址；正常部署仍要求 HTTPS 入口。没有 TLS 时仅允许回环监听并由 HTTPS 反代。已有的 `control-v3` 配置、数据库、账号初始化和角色启动方式见 [重构进度](V3-RECONSTRUCTION.md)。本地浏览器验收使用独立数据库 schema、合成记录和 localhost，不复用生产账号、连接子服务器或发送通知。

## 当前页面

### 登录

使用 v3 PostgreSQL 持久会话、CSRF 和账号权限。首次匿名访问显示登录表单；已有会话只有明确收到 401 才提示失效。502、503 和断网保留已显示内容，普通读取每三秒重连，后台标签暂停。写入不会自动重放。

### 监控总览

`/` 显示实际版本、更新时间、六组摘要、最多八条当前异常、十三张组件卡、资源排名和服务器资源表。后台工作器独立预计算九个分区，页面每三十秒读取缓存；后台标签暂停、返回刷新，未完成请求不重叠。分区失败保留旧数据并标记过期，缺失证据显示未知，首样本和重置不伪造零值。组件范围及尚缺少的运行证据见 [总览说明](V3-DASHBOARD.md)。

### 服务器管理

服务端按名称／IP／ID 和实际采集状态筛选，使用 20／50／100 条游标分页；不会一次获取全部服务器，也不虚构总条数或任意跳页。详情区分已保存配置和实际采集证据，分别显示配置版本、已生效版本、实际运行方式、Agent 版本及最近部署任务。缺失数据为“未知”或“—”，真实零值正常显示。

管理员可以保存节点登记元数据，使用配置版本检查及幂等键；成功提示“配置已保存，尚未部署”。添加／编辑提供现有凭据、指纹确认及部署准备流程，已安装节点独立升级使用已保存配置；任务创建后立即打开日志。私钥可拖入、选择文件及粘贴，关闭清空临时内容。弹窗正文内部滚动，底部反馈与按钮在小屏保持可见。公开卸载写接口尚未提供，对应入口禁用。

服务器登记保存前自动创建“编辑前”加密配置存档，备份与保存同事务提交；缺少独立密钥或备份失败时不保存，保留表单输入。同一幂等请求不重复创建存档，冲突或失败不留下部分配置。详见 [编辑前备份](V3-CONFIGURATION-BACKUPS.md#编辑前自动备份服务器登记及保留期限)。

### 网站监控

网站列表与详情沿用旧版列序、按钮、详情网格和故障表，使用服务端名称／网址、关联服务器和状态筛选，以及 20／50／100 条游标分页。翻页使用已提交条件，不把尚未提交的关键词带入查询。全站统计由数据库聚合，正常、故障、待检查、暂停、等待迁移切换及未知互相独立；迁入但尚未生效的网站不计入当前正常数。未知统计首次显示“—”，读取失败保留上一份统计并标注。

管理员和操作员可添加、编辑、暂停监控、提交手动检测，以及单条或当前页批量软删除。表单保存沿用配置版本与幂等键，失败保留输入，按钮附近持续显示结果，禁止重复提交；网络故障不自动重放写入。手动检测仅提示已加入工作器队列，不宣称检测成功。暂停网站不接受手动检测，待迁移网站禁止编辑、检测与删除，只读账号没有选择列和写按钮。

软删除确认固定明确选择的网站和版本，不隐含删除筛选下所有网站。服务端重新核对全部版本，冲突时整批不写入；取消检测并使旧结果失效，保留故障历史和通知，不生成恢复通知。当前游标页变空时退回已访问的上一页；深链接无前页记录时回首页。恢复通过备份管理中的网站配置预览与合并入口完成。

网站列表与详情完成后每三十秒刷新，后台或编辑／删除弹窗打开期间暂停；返回前台时重新读取。详情显示最近检查、HTTP、响应耗时、证书、配置版本；未检查不显示虚假耗时，真实零耗时正常显示。详情故障入口绑定网站 ID，告警页可清除此网站筛选再查其他网站。网站历史响应时间图和进一步完整详情仍需继续。

### 文件与安全事件

打开、刷新、带条件进入、前进后退只恢复筛选并加载一页服务器选项，不查询事件。点击查询或关键词回车才执行，默认最近二十四小时、每页二十条，探针默认排除。服务器选择支持远程搜索，不加载万台全量选项。

修改筛选只更新待查询条件和 URL，保留上一份结果；翻页继续使用已提交条件和该次查询的时间窗口。查询错误明确标注，旧成功或错误响应不能覆盖新查询。清除服务器后再次查询覆盖所有服务器。关键词查询文件路径、原因及消息，按字面匹配 `%`、`_`，覆盖原生和迁移历史。

自动刷新每次进入默认关闭，首次成功查询后才可开启。间隔只提供 10、30、60、120、300 秒下拉选项，沿用已确认的“去掉重复数字输入框”要求。间隔偏好按当前浏览器的 v3 用户名隔离；开关不持久化，不写 YAML，不影响监控采样。

刷新使用已提交条件并滚动相对时间，保留分页游标。修改筛选、后台标签或请求未完成时暂停；成功手动查询后恢复。自动失败保留数据并显示错误，完成后等待完整间隔再试，不积压请求。页面退出终止定时器和读取。删除导致游标页为空时向已访问的上一页退回，不提交正在编辑的筛选。

单条／批量删除使用已有账号绑定的历史预览和清理工作器。仅接受当前页明确选择的最多二百个稳定记录标识，服务端复查二十四小时、异常及任务保护；选择先导出时由服务端确保导出完成再删除。提交失败可用同一幂等键重试，结果显示删除、跳过及部分失败，不将创建任务当成删除成功。导出下载限定当前账号并检查完整性。普通记录删除不会立即收缩数据库文件，审计保护保持原有逻辑。

### 告警中心

提供当前异常、告警历史、飞书通知、邮箱通知四类列表。当前异常与历史分别选择服务器或网站来源；服务器选项远程搜索，列表由服务端按 20／50／100 条游标分页。历史可选择最近二十四小时、七天或三十天；翻页固定本次时间窗口，切换条件重新开始。当前网站异常不隐含二十四小时时限，排除已暂停、已删除和待迁移的网站，持续多日的真实异常仍可见。

页面自动读取，每次完成后等待三十秒刷新；后台标签暂停，返回后查询一次。切换页签、来源或筛选取消旧请求并清空勾选，过期结果与错误不覆盖新页面；网络短暂故障沿用共享重连反馈。读取失败保留旧结果；旧空结果在查询中、失败或筛选待更新时不会描述为当前没有异常。清理导致游标页为空时，退回已访问的上一页；无法还原访问轨迹的深链接回首页。

当前异常不提供删除。服务器及网站历史、两种通知的已完成历史使用既有删除预览与清理工作器，服务端复查保护条件；只读账号没有写入口。通知显示已完成、待发送、等待重试、等待前序、正在发送、已暂停或等待迁移切换，以及尝试次数和计划发送时间。详情只显示安全元数据，不返回通知载荷、通道响应、租约所有者或凭据；完整投递尝试明细和正文展示仍待实现。“已完成”不表示收件人已读或邮件已进入收件箱。

### 系统设置与存储清理

`/settings` 恢复旧版设置分类下拉，提供公共监控、网站检测、飞书通知、邮箱通知、历史与备份、存储与清理、操作审计。公共文件规则未由当前接口提供，保留原字段结构、显示“未提供”并禁用；服务器告警参数继续使用现有运行设置接口。运行设置已接网站检测、服务器告警及通知白名单字段的预览、保存和独立应用；启动参数、其余运行协调及部署配置实际应用仍需继续，不将此页面视作完整系统设置交付。

五项保留期限沿用 PostgreSQL 中的当前值，支持 1～3650 天整数。只有管理员可保存，缩短期限须确认不可逆影响，保存后立即生效。重新读取不会隐式覆盖草稿，明确放弃后才使用最新配置；发生并发修改时保留原期望版本及输入。同一请求明确重试使用原幂等键，修改内容后使用新键。反馈持续显示在保存按钮旁，新草稿清除旧成功提示。

保留期限保存也自动创建“编辑前”配置存档，备份失败阻止写入；系统设置没有新增删除按钮。保留期限继续独立保存并生效；运行设置另行预览、保存、应用，不顺带激活其他草稿。

自动清理状态显示工作器证据、最后任务及当前应用 schema 的业务表／索引大小。无心跳显示未知；大小不包含时序库、导出或其他项目的数据，不能作为磁盘空闲空间。当前接口尚未提供各类别数量及最早记录时间，页面不填造这些统计。

存储与清理默认截止 30 天前，可独立选择类别、服务器、截止时间及是否包含探针。预览固定范围和配置版本，有效十分钟，最近 24 小时及当前异常／未完成任务继续受保护。可以仅导出，也可明确确认清理；默认先导出，成功后才清理。修改范围后旧预览立即失效，提交失败保留原意图供明确重试，创建任务不显示为处理成功。任务详情每三秒更新，后台暂停、离开取消读取，已提交工作不因关页停止。部分完成保留真实清理／跳过／导出数量，下载检查完整性与有效期且不隐式重放。

本账号手动任务和自动清理分别由服务端分页，每页二十条；自动任务不会被当作手动下载任务。任务和审计均只读，**系统设置不增加单条或批量删除按钮**。范围清理继续使用原接口与保护。审计可以按账号、类型及最近一天／七天／三十天查询，翻页固定已提交条件和时间范围；只展示服务端允许的结果摘要，不暴露私有载荷。审计保留 365 天，当前页面尚未提供任意历史时间窗口选择。

### 备份管理

统一入口 `/backups?tab=website|deployment`，默认网站配置；旧 `/config-backups` 路径转至部署配置页签。网站配置和部署配置存档页已接入。部署配置提供管理员专用创建、分页、YAML／age 导入及脱敏／加密导出；已接入配置存档的单条／当前页批量删除、十分钟预览和本账号持久任务进度；已接入恢复到保存配置的预览、持久记录、本机只读检查和提交，运行应用仍待完成。

网站配置快照支持手动创建、导入原 format_version: 1 JSON、导出、合并恢复预览，以及单条／当前页勾选批量删除。列表由服务端每页二十条分页，翻页清除选择，删除空页时退回已访问的上一页。受保护备份禁止选择并显示原因，提交后逐项报告跳过，不将部分结果描述为全部成功。有效恢复预览引用的备份受保护，独立备份不套用历史 24 小时规则。

导入支持文件或粘贴，最大 2 MiB；保留原始 JSON 交由服务端拒绝重复字段，不通过浏览器先解析来丢弃重复键。读取竞争只接受最后选择，关闭后忽略迟到读取，异常保留原输入。导入只加入备份列表，不恢复网站。

恢复预览显示新增／更新／不变数量及不存在的节点，账号绑定凭据有效十分钟，配置或节点变化后必须重查。恢复在同一事务中先备份，再按规范化网址合并；缺失节点清除关联，软删除网站复用原身份，保留历史和队列。网站备份不包含数据库、故障历史或后台密码。小屏弹窗正文内部滚动，反馈和按钮固定可见。只读账号可列表／导出，不提供写入或选择列。

部署配置存档使用主控原始启动快照及同一数据库快照中的已保存设置、节点；不读取后来编辑的磁盘 YAML，不代表已生效。原生 v3 YAML 最大 32 MiB，age 包最大 34 MiB，仅存档导入，不触发恢复或部署。关闭弹窗、切换页签和离开页面清除临时密码／内容，并忽略迟到请求。纯 HTTP 禁用导入和加密下载；受信 HTTPS／反代、CSRF、幂等键和跨实例密码计算限流由服务端独立复查，不能只靠按钮禁用。配置备份不含外部私钥、PKI 或独立凭据文件。具体范围及未完成工作见 [配置存档说明](V3-CONFIGURATION-BACKUPS.md)。

部署配置恢复默认保留当前凭据，可明确使用备份凭据后重新预览；分步创建恢复记录、检查本机资料、准备候选、确认提交到保存配置。未完成记录可在页面刷新后继续，其他管理员仅能查看或取消。代次不经数值转换，失败重试沿用原幂等键；明确冲突要求重新预览。页面始终区分“候选已准备”和“已保存，待应用”，没有运行应用按钮；本机资料检查不连接远端或发送通知。

### 部署任务

任务列表由服务端分页，可以按节点筛选。详情显示持久化阶段、结果与错误。运行中每三秒读取，日志从已接受游标续读，每批一百条，页面最多保留最近一千条；后台标签暂停，恢复后继续读取。继续／回退按钮依据接口的实际恢复能力显示，核对计划摘要和最新游标，不凭任务失败状态猜测可恢复性。网页部署及宿主准备流程见 [网页部署与凭据](V3-WEB-DEPLOYMENT.md)。

## 权限与保护

全部业务接口使用 `/api/v3`。匿名业务请求要求登录，写入检查 CSRF、来源、角色和现有配置保护；只读账号不展示写入按钮。服务器详情在一个数据库快照中读取，响应不包含私有配置、凭据和部署计划。

HTML 不缓存，带防嵌入及来源策略；有内容摘要的静态资源可长期缓存。未知 API、旧 `/api`、目录穿越和未知页面不会落到 v2 页面。不同页面拥有独立请求取消范围，切换页面不让旧响应覆写当前内容。

## 验证范围

告警测试另覆盖四类列表、长时异常、切页取消、空旧结果、通知保护及大整数身份。Vue 挂载测试覆盖首次不查询、筛选与分页隔离、清空服务器、探针、刷新偏好、后台暂停、旧请求、失败重试、删除预览及部分完成；真实 PostgreSQL 测试覆盖权限、静态入口、敏感字段排除、关键词和迁移分页。实际浏览器使用合成的 24 个节点、44 条事件和一个失败任务，验证登录、分页、保存、日志、手动事件查询、小屏弹窗及导出清理。

证据和完整限制见 [验证记录](V3-VALIDATION.md)。总览的剩余组件证据、完整运行设置与部署配置恢复等其他网页，完整安装／升级、PKI 运维、最终迁移及回退、真实可选高可用和容量验收仍须继续。此网页阶段不构成完整 v3 发布条件。


## 节点保存与运行状态

服务器列表、详情分别显示保存、下发、生效版本。`仅保存` 不改变实际采集或告警；已保存停用而尚未部署时，运行监控仍显示当前登记状态。新增节点仅保存后显示“尚未登记”，不会提前采集。下发缺少可靠证据时显示“—”，不能把已有登记当作 Agent 安装成功。网页“保存并部署”和独立升级根据真实能力开放；升级使用已保存配置，确认预览后等待实际任务 ID，再跳转日志。细节见 [节点运行登记](V3-NODE-RUNTIME.md) 和 [网页部署与凭据](V3-WEB-DEPLOYMENT.md)。

## 运行设置

本地 v3 的“系统设置”分类下拉支持网站检测、服务器告警、飞书和 SMTP 参数。管理员先预览并保存，随后单独应用；保留期限继续使用独立页签，不顺带激活其他草稿。凭据仅显示配置标记，保留、替换、清除需明确选择，关闭页面清除临时输入。未设置值不伪造默认，未知配置不公开或覆盖。详见 [设置生命周期](V3-SETTINGS-LIFECYCLE.md)。

当前仍没有完整生产迁移入口；网页部署写入已接通，正式发布是否可用以 [发布验收记录](V3-FORMAL-RELEASE-READINESS.md) 为准。接口实现或局部通过不等于正式产物已发布。

## 单中心容器的界面与部署默认值

v3 界面复用 v2.0.46 的登录、侧栏、菜单图标、颜色、字体、卡片、表格及窄屏样式，数据继续通过 `/api/v3` 读取。事件仍须先手动查询，删除保护不变。网页安装、升级和 SSH 凭据管理按真实执行器能力开放；未就绪时展示具体原因。保存基本配置只表示保存成功，部署任务创建后立即进入日志，最终结果由任务确认。

`GET /api/v3/capabilities` 的 `deployment_defaults` 返回主控、子控默认 `docker`，子控可选 `docker`／`native`。新建表单、配置模板和 CLI 解析采用相同默认值；编辑和升级保留已保存方式。主控继续使用单中心 Docker 栈，PostgreSQL 和 VictoriaMetrics 独立于应用容器更新。


## UI 恢复后的只读展示

服务器列表／详情使用单次安全投影，资源曲线使用 `GET /api/v3/servers/:id/metrics`。该接口固定节点和指标白名单、最多 31 天／1000 点，时序库响应受限；断线缺口留空。当前仅支持汇总历史，磁盘／网卡历史选择器禁用，不把未提供的设备曲线显示为零。

飞书和邮箱页恢复七日堆叠图，使用 `GET /api/v3/notifications/stats` 的真实聚合计数，按北京时间、任务创建日期和当前投递结果分组；不等于收件人已读。以上只增加查询能力，不改变删除保护和部署写入逻辑。
