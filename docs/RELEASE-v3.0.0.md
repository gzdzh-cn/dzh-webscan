# v3.0.0 单中心发布说明

本文件描述本次源码和发布范围。正式镜像、签名及下载产物的实际状态以 GitHub Release 和发布回执为准；全部产物复核通过后才更新 `latest`。本次不自动升级线上主控或子控，测试边界见 [验收记录](V3-FORMAL-RELEASE-READINESS.md)。

## 核心功能

- 主控主动通过 gRPC／HTTP/2 和双向 TLS 采集子控，SSH 用于安装维护。业务数据使用 PostgreSQL，指标使用 VictoriaMetrics，子控 SQLite 保留待确认事件。
- 保留原后台的页面风格、事件手动查询、历史删除保护和登录会话持久化。新增主控、子控默认 Docker，native 保留可选。
- 网页支持 SSH 凭据、首次指纹确认、异步部署准备、安装、独立升级、任务日志、继续和回退。升级读取已保存配置，普通子控操作不重启主控。
- 私钥支持文件选择、拖入和粘贴，最多 64 KiB；凭据加密保存，不回显。API 与宿主执行器共用原 Vault，API 不持有 CA 私钥、Docker socket 或宿主部署权限。
- 运行设置先预览、保存，再明确应用；编辑前加密备份与修改在同一事务提交，失败保留原值。弹窗和设置页面在按钮附近持续显示结果。

## 本轮修复

- 接通此前关闭的网页部署写入流程，由宿主工作器准备证书、配置和签名目标；返回准备回执时继续轮询，取得真实任务 ID 后进入日志。
- 修复容器缺少原 Vault 挂载造成的设置故障；新安装与升级模板保留同一密钥和旧密钥清单。
- 兼容 Docker 29 containerd 的索引／平台镜像身份及嵌套 OCI 离线归档，保持完整摘要、配置、平台和层验证。
- 完整归档使用一次流式读取完成摘要及内容验证；生命周期校验和最终确认保留有上限的六分钟 SSH 时限，避免大镜像在原 75 秒时限中误失败。
- 镜像引用保留可读版本标签及固定摘要，例如 `webscan-agent:v3.0.0@sha256:…`；正式构建使用实际本版程序及 OCI 版本、源码标签。
