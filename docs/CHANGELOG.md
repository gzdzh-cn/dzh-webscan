# 版本更新说明

[返回 README](../README.md) · [SH 安装教程](INSTALLATION.md) · [日常维护](OPERATIONS.md)

## v2.0.37

- 统一备份管理入口与两个独立页签，兼容旧地址和已有 YAML 备份。
- 部署配置手动备份、脱敏 YAML 和标准 age 加密导入导出；凭据不进入预览与日志，恢复预览绑定账号与版本，有效 10 分钟，恢复为待应用。
- 网站批量软删除；历史明确勾选删除复用租约与清理工作器，保护近期、当前异常及未完成通知，处理重复迁移记录。
- 网站／部署备份文件删除采用持久化任务与可重放文件步骤；部署任务删除保留防重信息和回退资料；365 天只读审计。
- 子服务器逐台卸载验收与配置移除，失败保留配置，支持任务续作，关联网站转由中心检测，历史保留原节点；修复 Go 一体化单节点卸载对旧组件的依赖。
- 系统设置不增加删除按钮，普通升级只更新中心。

## v2.0.36

- 文件与安全事件首次打开不查询，筛选提交与翻页分离，默认排除链路探针；支持手动开启定时刷新及 10～3600 秒自定义间隔。
- 监控总览六组摘要、13 类组件状态和资源排名，补齐邮箱、扫描、网站调度、管理、看门狗及清理状态，分区失败保留已有结果并标记。
- 安全命中、网站及服务器故障历史支持独立期限，旧配置沿用原设置；SQLite 分批清理保护未完成任务及当前异常。
- 新增存储统计、清理预览、JSONL 导出、手动清理及审计，支持重启续作及跨数据库批次日志。
- 只需 `webscan --upgrade --central-only`，无需升级子服务器；同步部署包不切换生产服务。

## v2.0.35

- 子服务器整合文件监控、扫描、SQLite 事件确认投递和 Linux 主机指标，支持 native systemd／Docker 单容器。
- 新增节点默认 native，无 Docker 时通过 SSH 安装校验后的程序和扫描工具；旧三容器节点默认保留 Docker 并合并为单容器，后台可切换。
- Go 一体化中心内部采集主机资源，停用本项目旧 host-exporter；仍兼容旧节点指标。
- 断网补传、回执核对、永久拒绝隔离、旧 JSONL 幂等导入；回退保留当前数据库并重新导出未确认事件。
- 增加备份完成标记、中断恢复保护、磁盘预检、实际资源限制验收和单节点维护抑制。
- 后台显示配置／实际方式、版本及部署状态，“监控链路”改为“事件投递”。
- **本版需执行 `webscan --upgrade` 升级中心和子服务器**；发布同步不切换生产运行服务。

## v2.0.34

- 整合导航：系统健康进入主服务器详情，网站故障历史进入告警中心；旧链接兼容，详情左上角返回并保留列表条件。
- 修复文件事件及其他页面清除筛选后的空值参数、分页和旧请求竞争；筛选与 URL 同步。
- 增加默认关闭的 SMTP 邮箱配置，TLS／STARTTLS、最多 20 个收件人、独立限流及持久化重试，飞书和邮箱同时投递。
- 告警中心增加邮箱历史、每个收件人投递详情和 7 天统计，图表位置增至 17；宿主机看门狗支持邮件。
- 数据库增量迁移前创建一致性备份，原账号、网站、事件与队列保留；无需升级子服务器。

## v2.0.33

- 历史导入使用持久化保护标记，防止实时采集压缩未完成的历史数据；中断后标记保留，重试完成后解除。
- 压缩在同一写事务内读取原始数据、生成聚合和删除原始记录，并保留历史来源标识。
- 使用新检查点重放旧指标导入，补齐可能被旧压缩过程截断的指标字段。

## v2.0.32

- 历史指标导入在读取前预先取得 SQLite 写锁，避免实时采集同时写入时出现 `SQLITE_BUSY` 并中断迁移；取消任务时释放事务和连接。
- 迁移完成后按 Compose 项目与服务标签识别旧容器，支持 Compose 自动生成的容器名称，保留复用的外部服务和全部旧数据目录。
- 数据库写入争用时显示明确的中文重试提示。

## v2.0.31

- Go 采集、SQLite 指标与聚合、健康状态机、事件查询和飞书记录替代本项目四个监控组件。
- 统一后台增加服务器切换、16 个图表位置、文件事件、告警／投递历史、链路与宿主机健康。
- 宿主机 Unix Socket 管理服务支持节点表单、YAML 预览／备份／应用及持久化部署任务，容器不持有 SSH 私钥或 Docker Socket。
- 旧配置保留 legacy，分批迁移并验收后切换；数据库、账号、队列及旧组件目录保持，支持回退。
- 新 native 安装不再询问 Grafana；Compose 支持两服务启动与显式可视化接管。
- 修复 Vite 下划线辅助模块未被 Go 嵌入导致懒加载页面空白的问题。

## v2.0.30

[GitHub Release 与下载附件](https://github.com/gzdzh-cn/dzh-webscan/releases/tag/v2.0.30)

本次完善 SH 安装和维护入口：

| 新增功能 | 使用方式 |
|---|---|
| 一行安装 | 下载 `install.sh`，自动创建 `/root/webscan-deploy`，固定版本下载并核对脚本和示例 YAML 的 SHA256 |
| 首次配置向导 | 依次填写主服务器、SSL、管理入口、飞书、多目录和可选子服务器；脱敏摘要确认后保存 |
| 全局管理命令 | 宿主机 root 输入 `webscan` 打开菜单；升级、节点操作与恢复参数原样传递 |
| 重复执行保护 | 保留已有 YAML；有新版脚本时备份后更新，同版跳过重复下载，不自动降级或升级容器 |
| 无节点安装 | 支持 `nodes: []`、`deployment.node_order: []`，先使用主服务器和网站后台 |
| 交互新增节点 | 菜单 **4 → N** 录入并保存节点，随后直接安装所选节点及验收 |
| 权限与任务保护 | 目录和脚本 0700、配置 0600；拒绝不安全路径，锁定并发操作，未完成任务保留原版本及范围 |

### 首次使用

在 Linux amd64 主服务器的 root SSH 交互终端执行：

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/gzdzh-cn/dzh-webscan/releases/latest/download/install.sh | bash'
```

填写向导并保存，进入菜单选择 **1、安装**。首次向导已选 SSL 时，紧接着安装不重复询问。安装成功后按终端提示访问网站后台及 Grafana，并保存初始有效账号凭据。

### 已安装用户

已有配置会保留，不再重复初始化。再次执行一行命令可更新入口；完成后在任意目录输入：

```bash
webscan
```

选择菜单安装、升级或重装才会应用运行配置及目标镜像。单纯下载新脚本、同步部署包、发布镜像或更新 `latest` 都不会自动切换生产容器。已有任务尚未完成时，先按原版本及范围恢复，禁止重置配置。

菜单 1 和 2 继续保留 SSL 引导；菜单 5 选择协议后直接完成主服务器及全部启用节点的完整部署。协议切换不能仅升级主服务器。
