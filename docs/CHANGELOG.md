# 版本更新说明

[返回 README](../README.md) · [SH 安装教程](INSTALLATION.md) · [日常维护](OPERATIONS.md)

## v3.0.0（2026-10-30）

- 单中心正式首发：主控通过 gRPC／HTTP/2 和 mTLS 主动采集，PostgreSQL 保存业务数据，VictoriaMetrics 保存指标，子控 SQLite 保留待确认事件。
- 保留原后台风格与删除保护，接通凭据、指纹确认、异步部署准备、安装、独立升级、日志、继续和回退；普通子控操作不重启主控。
- 修复运行设置、共享 Vault、独立宿主执行器和 Docker 29 离线镜像身份校验；新增主控和子控默认 Docker，native 子控可选。
- 真实正式产物联合验收、16 个公开附件下载及签名校验通过，版本和 latest 摘要一致。[发布回执](RELEASE-v3.0.0-RECEIPT.md) · [安装入口](INSTALL-v3.0.0.md)
- 本轮未升级生产；高可用、容量认证和 v2 数据迁移另行执行。v2 旧在线命令不能直接跨版本升级。

- 沿用删除规则及数据保护。普通更新只需升级中心和宿主管理程序，无需单独升级子服务器；发布不自动切换生产服务。

## v2.0.44

- 登录会话保存 SHA256 摘要、账号版本、CSRF 和绝对到期时间，跨重启保留 12 小时有效期；退出、改密和终端重置持久化撤销。迁移前一致性备份失败即停止。
- 网络错误及 502／503／504 保留页面，每 3 秒重试只读请求；后台标签暂停，导航或退出取消。部署日志沿原游标继续，写请求不自动重放。
- 添加／编辑节点弹窗限制可视高度，标题和操作区固定，长正文内部滚动；窄屏单列和按钮换行，保留私钥拖入保护。

### 首次使用

在 Linux amd64 主服务器的 root SSH 交互终端执行：

```bash
bash -o pipefail -c 'curl -fsSL https://github.com/gzdzh-cn/dzh-webscan/releases/latest/download/install.sh | bash'
```

填写向导并保存，进入菜单选择 **1、安装**。首次向导已选 SSL 时，紧接着安装不重复询问。安装成功后按终端提示访问网站后台及 Grafana，并保存初始有效账号凭据。

### 已安装用户

已有配置会保留，不再重复初始化。再次执行一行命令可更新入口；完成后在任意目录输入：

```bash
webscan
```

选择菜单安装、升级或重装才会应用运行配置及目标镜像。单纯下载新脚本、同步部署包、发布镜像或更新 `latest` 都不会自动切换生产容器。已有任务尚未完成时，先按原版本及范围恢复，禁止重置配置。

菜单 1 和 2 继续保留 SSL 引导；菜单 5 选择协议后直接完成主服务器及全部启用节点的完整部署。协议切换不能仅升级主服务器。
