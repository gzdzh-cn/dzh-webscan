# v3 网页部署、SSH 凭据与恢复

本文件描述当前实现。正式发布是否可用，以 [发布验收记录](V3-FORMAL-RELEASE-READINESS.md) 为准；代码接通不代表全部真实环境验收已经完成。

## 宿主与 API 的职责

API 容器使用 `executor.mode: external`，只读挂载现有 Vault 密钥、必要的旧 Vault 密钥、验签公钥、发布清单及签名。API 不挂载 CA 私钥、宿主执行程序、私有配置包目录或 Docker socket。`embedded` 保留给宿主或既有非容器配置；省略 `mode` 沿用旧行为。

宿主运行 `--action run --role executor`，加载完整的 `deployment_trust`、`node_pki.authority_directory`、`executor.configuration_directory` 和 `executor.rules_file`。宿主工作器负责证书签发、规则绑定和私有配置包准备；同一把原 Vault 密钥用于 API、执行器、编辑前备份和加密凭据。不能重新生成密钥来修复无法解密的已有数据。

能力接口 `/api/v3/capabilities` 的 `settings`、`deployments`、`executor` 返回 `available` 和脱敏 `reason`。部署能力要求 API 能验签并读取正确密钥，同时存在匹配发布清单及密钥的执行器、部署准备工作器新鲜心跳，签发器和规则实际可读。配置开关开启不代表可用。

## 网页操作

1. 添加或编辑服务器，默认 Docker，native 可选。“仅保存”显示“配置已保存，尚未部署”。
2. “保存并部署”先保存配置，再准备安装或升级。已有节点的“升级子服务器”使用已保存版本，不保存弹窗草稿。
3. 首次配置 SSH 时读取已保存节点地址的主机指纹。管理员确认后固定；后续发现不同指纹即停止，不能自动接受变化。
4. 指纹确认和部署预览各有效十分钟，绑定管理员账号版本、节点版本、SSH 地址及端口、凭据状态、部署状态和签名目标摘要。变更后重新预览。
5. 预览确认后先得到准备回执；轮询得到真实 `result.job` 后跳转任务日志。这只表示任务已创建，不表示安装成功。
6. 存在未完成部署时打开原任务，按实际状态继续或回退。日志按游标续读；恢复请求核对原计划摘要及最新游标，重复请求复用幂等键。

弹窗正文内部滚动，底部持续显示进度和错误。关闭或重开后忽略迟到结果；私钥临时内容不持久化到浏览器存储。网络失败保留输入，使用同一操作的幂等键重试。

## SSH 认证

支持密码、未加密 OpenSSH／PEM 私钥内容、主服务器受控路径，最多选择一种。编辑全部留空保留；新增必须提供有效认证内容。浏览器拖入、选择文件或粘贴均按内容读取，单文件最大 64 KiB，不将本地文件路径当作主服务器路径。

路径仅由宿主读取。默认受控目录为 `/var/lib/webscan-deploy/ssh-keys/` 和 `/root/.ssh/`，可通过宿主 `executor.ssh_key_directories` 明确配置。拒绝符号链接、不安全目录或文件权限，不接受任意探测命令。私钥必须能由现有 Go SSH 库解析；公钥、损坏内容和需口令私钥拒绝。

认证内容只保存于独立加密注册表，不进入 YAML、部署计划、响应、日志或审计；接口只返回已配置标记、版本、端口和公钥指纹。临时准备输入和结果使用绑定请求及用途的 AEAD，十分钟到期清除。

## 接口

所有写操作要求管理员、可信 HTTPS、CSRF、`Idempotency-Key` 和当前配置版本。请求拒绝重复键、未知键、大小超限和命令／程序／证书路径注入。

| 路径 | 方法 | 返回 |
|---|---|---|
| `/api/v3/servers/:id/ssh-credential` | GET / POST | 配置标记／202 准备回执 |
| `/api/v3/servers/:id/ssh-fingerprint` | POST | 202 指纹读取回执 |
| `/api/v3/servers/:id/deployment-preview` | POST | 202 部署准备回执 |
| `/api/v3/deployment-preparations/:id` | GET | 原管理员的阶段、结果或脱敏失败原因 |
| `/api/v3/deployments` | POST | 202 确认准备回执，完成后返回真实任务 ID |
| `/api/v3/deployments/:id/resume` | POST | 原任务重新排队 |
| `/api/v3/deployments/:id/rollback` | POST | 原任务回退排队 |

完整请求格式见 `/api/v3/openapi.yaml`。准备失败不建立需要远端回退的安装状态；真正执行后沿用持久化检查点、租约及远端凭据。旧不可变任务不改写，恢复时须提供该任务原发布资料。

## 运行设置

沿用设置读取、预览和确认接口。预览不保存；确认保存或应用时，在同一数据库事务中捕获加密编辑前备份、修改配置及记录审计。密钥缺失、错误密钥、旧密钥缺失或备份失败均停止，保留原配置。只读挂载并非禁止 API 使用密钥加密，禁止的是 API 修改密钥文件。

通知验收使用模拟通道；不能为验证部署触发业务飞书或邮件。
