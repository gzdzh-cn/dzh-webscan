# v3.0.2 失效服务器记录移除修复

服务器管理增加“移除记录”和“移除已选记录”。失联或已取消的节点也能从中心移除，不依赖 SSH；确认后停止采集，保留历史事件、指标、任务和审计，不卸载远程程序。

- 单条或当前页明确勾选，最多 200 台；确认框显示目标、影响和持续操作反馈。
- 关联网站、未完成部署、需要恢复的任务、有效部署准备或身份维护任务阻止移除，并显示具体原因。
- 管理员、可信 HTTPS、CSRF、配置版本与幂等校验；编辑前加密备份、批量移除和审计同一事务提交，任一冲突整批保留。
- 运行登记撤销并递增代次，旧采集请求不能继续提交；管理列表、总览、配置导出和部署入口排除已移除节点。
- 节点 ID 留作历史关联，不能复用。重新接入使用新的节点 ID。

数据库从版本 35 增量升级至 36，升级前必须完成一致性备份。补齐版本 36 的 PostgreSQL 灾备恢复，恢复后不会重新采集已移除节点。升级不会自动移除现有记录，也不改变历史数据的删除保护。

安装及升级见 [本版安装指南](INSTALL-v3.0.2.md)。中心、子控镜像均从本版源码构建，使用可读的 `v3.0.2` 标签、固定摘要和签名资料；生产只更新中心，子控可保持当前版本。

本补丁沿用 v3 单中心范围，高可用、万台容量认证及远程卸载不在本版交付范围。实际构建、验收结果及限制随发布附件 `acceptance.json` 提供。
