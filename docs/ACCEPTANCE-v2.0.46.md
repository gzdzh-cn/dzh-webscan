## 提示文案

服务器列表、添加及编辑子服务器弹窗统一直接展示：

- 子服务器放行入站 TCP 22、19100，仅允许主服务器访问。
- 主服务器放行入站 TCP 19443，允许子服务器访问；子服务器同时允许出站连接该端口。
- 云安全组、宝塔防火墙和系统防火墙都要检查。自定义端口以实际配置为准。

移除冗长说明、展开入口和逐节点端口表，保留简短环境要求。按当前部署方式显示 systemd／资源控制或 Docker／Compose 要求；已启用 ClamAV 时提示提前配置 clamd。配置读取失败仍明确提示并允许重试。

## 升级与边界

仅调整提示展示，不改变接口、认证、主子服务器通信、部署、删除或通知行为。

发布不切换生产服务，现有子服务器无需升级。用户主动执行：

```bash
webscan --upgrade --central-only
```
