# v2.0.37 验证记录

验证使用隔离 SQLite、虚构网址和收件人，飞书与邮件均关闭。发布同步不切换生产服务，不卸载生产节点。

## 已通过

- 前端 TypeScript 检查、29 项 Vitest、Vite 构建；生产界面嵌入 Linux amd64 Go 二进制。
- 全量 Go 测试；记录操作、清理、宿主管理和中心的 race 检查。
- 独立 SQLite 写入器与事件接收并发：先获取写事务，再读取去重状态，避免 WAL 快照升级失败；重复测试与 Linux amd64 镜像测试通过。
- Linux amd64 镜像中的宿主管理、清理测试与真实镜像启动验收：后台资源、登录保护、内部主机采集。
- 标准 age 格式加密往返、错误密码、HTTP 凭据导出拒绝、脱敏无密码／私钥／敏感地址／注释、导入不修改 YAML。
- 预览绑定账号、配置版本、备份摘要、凭据选项和 10 分钟有效期；有效预览期间备份不可删除。
- 节点凭据按唯一 ID 匹配；网站软删除递增版本、保留故障与通知；移除关联保存历史原节点。
- 明确记录标识删除、保护近期与待投递关联记录、并发内容变化跳过、迁移重复展示记录同步删除。
- 持久化删除任务防重、账号隔离、重启重放文件墓碑、符号链接及任意路径拒绝。
- 部署任务历史归档后不可见，日志删除，但重复请求仍返回原任务，不重新执行部署。
- 子服务器移除阶段测试：模拟 SSH 失败保留配置并暂停后续节点，继续时不重复完成的节点，更新 YAML 和部署顺序。
- 隔离 Linux 容器执行真实卸载脚本，替身 systemd／Docker 命令验证 native、Docker、Docker 不可用失败、重复执行及数据库／业务文件保留。没有连接生产 SSH 节点。
- v2.0.36 → v2.0.37，以及 v2.0.35 → v2.0.37 的隔离镜像迁移：账号哈希、网站、故障、事件、待投递任务及收件人数量保持一致，SQLite 一致性检查正常，迁移前备份存在。
- 真实浏览器：统一备份页签、手动网站／YAML 备份、恢复预览、HTTP 加密按钮禁用、旧备份地址跳转；事件首次不查询、近期记录禁选、当前页勾选两条的预览准确。

永久删除的执行与中断保护由隔离后端测试验证；浏览器验收只打开范围确认，不提交生产删除。系统设置不增加删除按钮；已有“存储与清理”及只读审计保留。

## 交付核对

版本产物：`dist/v2.0.37/`，包含中心／Agent 镜像、native 包、引导脚本、安装入口及校验清单。镜像发布后核对版本标签与 `latest` 的公开摘要以及本地镜像身份；部署包同步前后核对 YAML、运行配置、部署凭据、状态、容器标识／启动时间及管理服务 PID。

常规升级只更新中心：

```bash
webscan --upgrade --central-only
```
