# 网站可用性后台使用指南

[返回 README](../README.md) · [配置参数](PARAMETERS.md) · [Grafana 查询](GRAFANA.md)

本功能检测“主服务器能否打开网站首页”。不扫描内页，也不执行 JavaScript。文件安全监控仍由子服务器 Agent 执行。后台采用 Vue 3 + Vite + Element Plus，随主服务器 GoFrame 程序提供页面和接口。

| 页面或入口 | 可以做什么 |
|---|---|
| 监控概览 | 查看网站总数、正常／异常数量及近期故障 |
| 网站管理 | 筛选分页、添加编辑、暂停／恢复、立即检查；查看响应耗时、证书有效期，复制或打开网址 |
| 网站详情与故障历史 | 查看 HTTP 状态、最近检查、故障原因和恢复记录 |
| 备份管理 | 本地备份网站配置、查看历史、JSON 导出／导入、预览后合并恢复 |
| 右上角修改密码 | 持久化管理员新密码并撤销全部登录会话 |

## 开启与登录

从完整示例复制以下区块到实际 YAML 的 `central` 下：

```yaml
central:
  website_monitor:
    enabled: true
    bind_address: 0.0.0.0
    host_port: 19444
    admin_username: admin
    admin_password: ''
    interval_seconds: 60
    timeout_seconds: 5
    max_concurrent: 128
    extra_memory_mib: 128
```

该片段不能替代完整 YAML。旧配置未填写时不开启后台。端口不能与其他服务重复；检测间隔允许 10～3600 秒，超时 1～30 秒且必须小于间隔，并发允许 1～128；额外内存至少 128 MiB。密码留空自动生成，手动填写需要 12～72 字节。

已有系统在主服务器执行以下命令应用后台配置；无需更新子服务器：

```bash
cd /root/webscan-deploy
bash deploy-webscan.sh --upgrade --central-only
```

该命令仅用于现有协议下启用或调整后台。**变更 SSL 总开关时，使用菜单 5 或 `--set-ssl on/off` 完整部署主服务器和全部启用节点**；不能仅执行 `--central-only` 切换协议。

SH 首次安装显示初始账号密码；初始凭据保存在 `/var/lib/webscan-deploy/credentials.json`。Compose 初始凭据在 `central/website-credentials.json`。文件权限为 0600，不要分享整份文件。网站后台账号独立于 Grafana。

v2.0.29 起账号以 SQLite 中的持久化记录为准，YAML 仅用于初始化；升级、重启和保留数据的重装沿用后台修改后的密码。改密后的旧初始密码不再有效，升级输出也不会显示失效密码。服务重启或改密后需要重新登录。

## 面板端口与访问方式

后台默认端口 **19444**，通过 `central.website_monitor.host_port` 自定义。Grafana 的 **3000** 和节点事件接口的 **19443** 不是网站后台入口。

| 方式 | 浏览器地址 | 配置与放行要求 |
|---|---|---|
| IP 直接访问 HTTPS | `https://主服务器IP:19444/login` | `ssl.enabled: true`；绑定外部可访问地址，允许管理来源访问 TCP 19444 |
| IP 直接访问 HTTP | `http://主服务器IP:19444/login` | `ssl.enabled: false`；同样放行 TCP 19444 |
| 同机宝塔 HTTPS 域名反代 | `https://monitor.example.com/login` | 对外放行 TCP 443；后台绑定 `127.0.0.1` 时不向公网开放 19444 |

直接访问时，**宝塔／系统防火墙和云安全组都需放行 TCP 19444**。只在宝塔中放行，不代表云安全组已放行；只放行端口，后台绑定 `127.0.0.1` 也无法从公网直接访问。修改监听地址或端口后执行主服务器升级使配置生效。

SSL 总开关同时控制节点通信、指标采集和后台，旧 YAML 缺省为 HTTPS。关闭后仍保留端口，后台地址改为 HTTP；它不改变宝塔域名对外 HTTPS、飞书及被监测网站的 HTTPS。

直接 HTTPS 使用部署 CA 签发的证书，浏览器需信任该 CA。可通过已验证的 SSH 下载 `/opt/webscan-central/webscan-v1/pki/ca.crt`，核对证书 SHA256 指纹后导入客户端信任库；macOS 可在“钥匙串访问”导入并设置信任。只下载 `ca.crt`，不下载或公开 `.key` 文件。也可使用下方具有可信域名证书的反代入口。

## 宝塔域名反向代理

以下示例适用于**宝塔与后台在同一台主服务器、后台使用 HTTP**的场景：

1. 域名 `monitor.example.com` 解析到主服务器，在宝塔创建该域名网站并配置可信 HTTPS 证书。
2. 后台设置 `central.website_monitor.bind_address: 127.0.0.1`，端口保留 `19444`；现有 HTTP 部署用 `--upgrade --central-only` 应用。若从 HTTPS 切换 HTTP，先用菜单 5 完成全部节点协议切换。
3. 宝塔网站反向代理目标填写 `http://127.0.0.1:19444`，代理路径 `/`。
4. 检查反代配置，**替换原有 Host 设置，不要重复追加同名指令**：

```nginx
location / {
    proxy_pass http://127.0.0.1:19444;
    proxy_set_header Host $http_host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

以上是位置区块示例；宝塔已经生成 `location /` 时在该区块内修改，不再另建重复区块。保存、检查配置并重载 Nginx，然后打开 `https://monitor.example.com/login`。公网只需开放入口 TCP `443`；如启用 HTTP 跳转，再开放 `80`。同机反代且后台绑定回环地址时，`19444` 只在本机访问。

**不能把 Host 设置为 `127.0.0.1` 或上游 IP**，否则浏览器 Origin 与后台收到的 Host 不一致，登录会提示“请求来源不正确，请从管理后台操作”。保留真实 Host 和访问协议即可；不要改写 Origin 或关闭来源／CSRF 校验。通过 HTTPS 域名登录时，登录 Cookie 保持 Secure。

如果保留后台 HTTPS，回源地址也需使用 HTTPS，并在 Nginx 配置可信 CA 和证书名称校验，不能直接套用上述 HTTP 回源示例；原有节点通信不必为域名入口改变协议。

## 访问与登录问题排查

| 现象 | 优先检查 |
|---|---|
| 一直连接、无法访问 | 协议是否匹配、receiver 是否运行、后台是否开启、绑定地址、云安全组和系统防火墙 |
| 浏览器证书不受信任 | 信任部署 CA，或使用宝塔可信域名证书反代 |
| 请求来源不正确 | 反代 `Host` 是否保留浏览器域名，是否错误设置成上游 IP；替换为 `$http_host` |
| 登录已失效 | 服务重启／改密后重新登录；检查代理协议头；曾经 HTTPS 改 HTTP 时可能需清除此站点的旧登录 Cookie |
| 账号或密码不正确 | 使用网站后台独立账号及最新密码；改密后初始凭据无效，忘记密码见下方重置命令 |

在主服务器本机检查默认安装：

```bash
cd /opt/webscan-central/webscan-v1
docker compose ps receiver
docker compose logs --tail 80 receiver
# HTTP 模式
curl -I http://127.0.0.1:19444/login
# HTTPS 模式（-k 仅用于本机诊断）
curl -k -I https://127.0.0.1:19444/login
```

选择与实际 SSL 模式一致的 curl 命令，端口和路径自定义时相应替换。本机返回 200 只说明页面可用，外网仍需检查网络与反代。旧版本若持续重启且日志包含 `ghttp.(*errorLogger).Write` 空指针，应升级到 v2.0.22 或更新版本。

## 添加与管理网站

进入“网站管理”，点击“添加网站”：

| 字段 | 填写方法 |
|---|---|
| 网站名称 | 便于辨认的名称，最多 100 个字 |
| 首页地址 | 完整公网 HTTP/HTTPS URL，例如 `https://www.example.com/`；可填写包含查询参数的首页地址 |
| 关联服务器 | 可选，仅用于分类和告警汇总；主服务器负责检测 |
| 首页关键词 | 可选，最多 200 个字；选择首页必定包含的公司名或标题 |
| 响应缓慢告警 | 默认关闭；响应超过 3 秒并持续 5 分钟后提醒 |
| 暂停检测 | 保留网站设置，暂停任务，不会因此发送恢复通知 |

最多添加 1000 个网站；地址会规范化，不能重复添加。禁止内网、回环、链路本地、云元数据及保留地址，域名和每次跳转都受检查。编辑和添加即时生效，不需要重新构建容器。

“立即检查”加入统一调度，不绕过并发限制；结果可能需要等当前任务完成。页面每 15 秒刷新，浏览器标签页隐藏时暂停页面刷新，后端检测继续运行。

删除为软删除，停止检查但保留历史；暂停、删除、更换 URL 不产生恢复通知。“已结束”的历史也可能由编辑或暂停终止，不能仅据此认定网站恢复。

## 检测与通知如何判断

```text
每 60 秒 GET 首页（总超时 5 秒，最多跳转 5 次）
→ 最终 HTTP 200，并满足设置的关键词
→ 保存状态和连续成功/失败次数
→ 连续失败 3 次：网站故障
→ 连续成功 2 次：网站恢复
→ 飞书持久化队列：限流、断网重试、按顺序发送
```

404、其他非 200 状态、关键词缺失、超时、DNS／连接错误和 HTTPS 校验失败均可判为检测失败。**不是停止网站后立即通知**：需要完成连续 3 次失败检查，再等待通知汇总及队列投递；请查看最近检查时间和故障原因，确认任务确实执行。

超时包含 DNS、连接、HTTPS、跳转和读取首页。只检查解压后的前 256 KiB，支持 UTF-8 和 GBK，不保存网页正文。返回 200 但显示业务错误的页面，建议设置关键词。不同地区的可访问性可能不同，检测结果以主服务器所在网络为准。

- 故障持续期间每 4 小时提醒；恢复通知包含故障持续时间。
- 证书剩余时间不超过 7×24 小时即提醒，与首页失败次数独立；每天最多提醒一次，首次进入过期状态立即补发一次。续签到超过 7 天后通知恢复。
- 慢响应启用后，连续两次不超过 3 秒时通知恢复。
- 同类通知按关联节点收集 15 秒：不超过 5 个网站逐条发送，超过 5 个汇总前 5 个、总数及后台链接。
- 故障与恢复记录、连续计数及未发送通知重启后保留；恢复通知不会越过尚未送达的故障通知。
- 飞书关闭时不生成新通知；故障历史仍记录。检测队列长时间积压或调度停滞会产生独立的运行提醒。

故障历史保留 30 天，仍在持续的事件继续保留。历史与网站设置在已有事件 SQLite 数据库中，随一致性数据库备份保存。旧服务回退时新增表保留，旧文件监控服务仍可读取其原有表；旧版本不提供网站后台。

主服务器升级或生成 Compose 包时会加入“网站可用性”看板。显示访问状态、响应耗时、成功率、HTTP 状态、证书剩余天数和调度健康。详细查询见 [Grafana 指南](GRAFANA.md#网站可用性)。

## 修改管理员密码

右上角点击“修改密码”，填写当前密码、新密码及确认密码。新密码为 **12～72 字节**，中文字符通常占 3 字节。成功后所有会话退出，使用新密码登录；服务器只保存 bcrypt 哈希。

后台改密不需要重建容器。YAML 的账号密码不会覆盖已初始化的数据库账号，升级验收通过仅内部可访问的管理令牌接口完成，不会使用旧明文密码。回退旧镜像时，部署工具会把当前密码哈希写入恢复后的运行配置。

忘记密码时，以 root 在主服务器交互终端执行：

```bash
docker exec -it webscan-v1-receiver-1 webscan website-password \
  --config /opt/webscan-central/webscan-v1/runtime.json
```

如果安装路径或容器名称自定义，请替换对应值。也可在已安装 Go 程序的 root 终端运行 `webscan website-password --config <运行配置>`。密码输入不回显，需要输入两次；不接受密码命令参数或管道。重置后运行中服务的旧会话也会失效。

## 网站配置备份与恢复

侧栏打开“备份管理”：

1. **一键备份**：保存所有未删除网站，含暂停网站；不受网站列表筛选影响。服务器保存到 `central.backup_dir/website-config/`，目录权限 0700、文件 0600。
2. **导出 JSON**：下载指定备份。仅包含网站名称、完整网址、关联节点、关键词、慢响应开关和暂停状态；不包含账号密码、故障历史、检测计数、文件事件或通知队列。
3. **导入 JSON**：校验后进入历史列表，**不会立即改动网站**。导入单文件最多 2 MiB、1000 个网站（服务器本地备份支持保存全部合法网站配置，超过 2 MiB 的导出文件不能直接再次导入）；不支持的版本、无效参数和重复网址整体拒绝。
4. **恢复**：先预览新增、更新和不变数量，再确认合并。按规范化网址匹配，当前列表中其他网站保留；未知关联节点会清空关联并明确提示。

每次恢复前自动备份当前配置，失败就停止；合并使用数据库事务，失败不留下部分结果。预览后若有配置变更，需重新预览。已有同网址软删除记录时优先恢复最近的一条，沿用网站编号及历史；合并后最多 1000 个未删除网站。

未变更的网站保留状态；检测配置变更后取消旧任务并重新调度。恢复本身不会发送“网站恢复”通知，原故障历史和已排队消息保留。备份历史显示最近恢复结果，手动备份永久保留，本功能不另设定时备份。现有全系统 SQLite 备份会同时归档网站备份文件，保持历史元数据与文件对应。

JSON 格式示例：

```json
{
  "format_version": 1,
  "created_at": "2026-10-09T00:00:00Z",
  "websites": [
    {
      "name": "示例官网",
      "url": "https://www.example.com/",
      "node": "",
      "keyword": "公司名称",
      "slow_alert": false,
      "paused": false
    }
  ]
}
```

## 证书有效期与网址操作

列表“证书有效期”显示剩余天数、已过期、未知或不适用。正数天数向上取整；告警按实际秒数判断，恰好 7 天也会提醒。详情显示证书检测域名、到期时间和最近检查时间。

HTTPS 地址检查填写的域名；HTTP 跳转时检查首个 HTTPS 域名。纯 HTTP 显示“不适用”。过期证书握手失败仍记录证书信息，网站继续被判为检查失败，不会关闭 TLS 校验。网络失败保留最近证书数据并标注“检查失败”，不误发证书恢复通知；404 或关键词不匹配不会抑制到期提醒。

网站名称进入详情；点击完整网址在新标签页打开。旁边复制图标复制协议、路径及查询参数，成功提示“网址已复制”。HTTP 后台也有兼容复制方式；浏览器拒绝复制时会显示可选中的完整网址，供手动复制。

## v2.0.29 升级

仅升级主服务器，无需升级子服务器：

```bash
cd /root/webscan-deploy
bash deploy-webscan.sh --upgrade --central-only
```

首次启动新版后台时，增量迁移前自动创建一致性数据库备份；备份失败则停止迁移。已有网站、故障历史、文件事件和通知队列保留，通信协议、端口及网站检测来源保持现有配置。生产升级由管理员手动执行。

前端构建、Vite 代理与镜像发布步骤见[本地开发指南](DEVELOPMENT.md#vue-本地开发与发布)。
