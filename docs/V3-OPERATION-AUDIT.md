# v3 操作审计与旧记录承接

当前为本地重构实现，完整 v3 尚未完成，不支持生产切换。本模块承接已结束的删除、清理和导出操作证据，不执行旧操作，也不恢复其预览或下载授权。

## 迁移范围

| 旧 SQLite 表 | 承接内容 | 不恢复 |
|---|---|---|
| `record_operations` | 网站、网站备份、部署备份、部署历史删除的原编号、操作人、类别、时间、选择范围和成功／跳过／失败数量 | 删除执行器、原请求键和原始失败文本 |
| `retention_jobs` | 已完成或失败的清理／导出任务、原编号、操作人、时间、范围摘要及实际处理数量 | 旧预览、游标执行授权、导出文件及下载权限 |

原始归档仍保留旧记录全部字段。业务审计只映射受控字段，不复制任意错误文本、文件路径、提供商响应、请求键或预览凭据。保留原完成时间，按原时间计算 365 天期限，不因导入延长保留期限。

中央事件库和宿主管理库可能各有 `record_operations`。分别归档，再对每个 SHA256 调用迁移命令；领域及原身份绑定完整来源摘要，相同旧编号不会冲突。新 PostgreSQL 审计 ID 独立分配，原编号和来源仍可追溯。

```bash
# 已使用 archive-v2 完成一致性快照及暂存后，在隔离环境执行。
.cache/webscan-v3 control-v3 --config /绝对路径/隔离配置.yaml \
  --action map-operation-audit-v2 --source <归档报告中的 SHA256>
```

迁移先检查源表清点及完成状态。发现排队、运行或不支持状态的旧任务时，在绑定目标前停止，要求先在旧系统处理并重新归档；不自动完成、取消或恢复旧任务。结束状态仍需核对选择、结果、游标、时间和计数，不能仅凭 status 判定成功。

复用迁移租约、每批最多 500 条及受限字节预算、未处理批次的摘要核对和持久检查点。失败回滚当前批次，保留此前完成数量；修复问题后对同一源继续，不重复写入。数据库错误不回传私密 DETAIL。完成后仍有迁移冻结，`ready_for_cutover` 为 false；该命令不是最终切换授权。

## 只读查询

`GET /api/v3/audit` 要求登录，支持 `actor`、`kind`、`start`、`end`、`cursor`、`limit`。默认最近 24 小时，单次范围最多 31 天，每页 1～200 条；下一页沿用返回的时间范围。按时间及数值 ID 倒序，ID 通过十进制字符串返回，避免客户端大整数取整。

- 管理员可以查看全部账号；operator／viewer 只能查看本人及 system 的记录。筛选参数不会扩大权限。
- 返回经过类型筛选的数量、状态、范围摘要和原身份，不直接返回任意审计 JSON。
- 所有记录 `can_delete: false`，说明为“审计只读，按 365 天期限保留”。不提供创建、更新、删除及批量删除接口。
- 数据库故障返回 503，不能伪装为空列表或登录失效。

过期清理仍使用持久化租约及 500 条批次。迁移冻结期间暂停审计过期清理，避免承接尚未完成时删除证据；最终切换流程尚未完成，不能用直接改数据库解除冻结。数据库一致性备份／空库恢复保留审计及其来源。

TypeScript SDK 与 OpenAPI 已同步；现有 Vue 页面尚未接入。宿主管理 `jobs`／日志、防重记录、配置恢复审计、未完成部署及卸载任务的正式承接仍需后续实现，本模块不能代替完整旧任务迁移。
