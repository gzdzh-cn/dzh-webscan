# v2.0.25 安装及重装 SSL 引导修复

## 修复内容

v2.0.24 仅在没有历史部署记录时为安装提供协议引导，重装没有接入。v2.0.25 的正常交互安装和重装均显示 HTTPS/HTTP 选择，已有安装记录也询问；回车沿用 YAML 当前设置，0 返回，输入结束不保存配置或执行安装。

重装选择协议后继续真正的全项目重装，保留历史数据和账号，不转换为普通升级。支持显式 `--reinstall --set-ssl on/off`；无人值守安装/重装使用 `--non-interactive` 沿用 YAML。菜单 5 继续自动完整部署。

继续未完成安装时保留原任务配置，终端明确说明为何不重新选择协议；未完成部署或卸载期间禁止选择新协议重装。已有系统显式 `--upgrade` 沿用 YAML，不增加交互；帮助、检查、预览和局部操作不弹出全项目协议引导。

## 验证

- Go 全量测试及 bootstrap 竞态检查、go vet 通过；前端类型检查、6 项测试和 Vite 构建通过。
- Linux amd64 实际 SH 包完成 14 个隔离场景：首次安装、已有安装切 HTTP/HTTPS、全新环境重装、已有安装重装切 HTTP/HTTPS、回车沿用、显式非交互重装协议、菜单 5、下载失败、部署工具失败、未完成任务拦截、返回和输入结束。
- 模拟部署入口核对实际参数：已有安装传入 `--upgrade`，重装始终传入 `--reinstall`，协议参数保存后不传给部署工具。保存后部署锁释放，引导锁仍持有，临时引导容器提取后删除。
- 修改前 YAML 备份、原子保存及权限保护沿用已验收流程。此版不修改网站检测、事件接收、扫描、传输或数据库逻辑；相关 Go 回归测试通过。
